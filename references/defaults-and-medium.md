# 默认矩阵：媒介、形式与交付默认值

默认值是起点，不是法律。先读任务契约里的**媒介、形式、导演模式与用途**，再选默认值；用户硬约束、平台参数与作品意图优先于任何模块默认值。

## 1. 四个维度先分开

| 维度 | 回答什么 | 常见选项 | 不要混成 |
| --- | --- | --- | --- |
| 题材／情绪 | 故事属于什么类型、要什么情绪 | 动作、恐怖、爱情、喜剧、科幻、奇幻、犯罪、悬疑 | 把“动画”“故事板”“广告”当题材 |
| 媒介 | 画面由什么材料与运动规则构成 | 真人、二维动画、三维动画、定格、混合媒介、未指定 | 把媒介当画风；把真人物理强加给动画 |
| 形式 | 交付物是什么长度与用途 | 单条短片、广告、故事板、长视频、系列、预告、预演 | 把故事板当类型；把广告当题材 |
| 导演模式 | 用什么态度组织场面 | 写实、诗意、实验、商业、类型化、纪录片 | 把“现实主义”只当滤镜 |

“动画”是媒介，“故事板”是形式，“广告”是形式／用途，“现实主义”是导演模式。一个任务可以同时有多个题材，但媒介与形式应分别写清。

## 2. 默认矩阵

声音与文字的默认值不是「全类型禁声」，而是**未经要求不擅自添加**：先看任务目的属于音乐主导、声音设计主导、信息主导，还是未指定声音偏好，再决定要不要音乐、旁白和画面文字（见第 4 节）。原著必要内心声与叙述保留原载体；明确静音才不加任何音轨。画幅、帧率、镜长按用户与作品需要决定，不由平台默认反向改变完整创作稿。

| 媒介／形式 | 组织重点 |
| --- | --- |
| 真人叙事、文戏、纪录片 | 表演、观察、环境与事实边界 |
| 广告、产品展示 | 实际产品、已知卖点、物理与品牌事实 |
| 二维、三维、定格动画 | 媒介材质与动作语法，按题材组织 |
| 故事板、预演 | 画面内信息与板外制作标注分开 |
| 长视频、系列 | 跨段状态、事件、场景和声音承接 |
| 实验、超现实、梦境 | 按作品意图选择留白、跳切与内部规则 |
| 未指定媒介 | 采用中性影像语言，不虚构参数 |

## 3. 未指定时怎么判

- **媒介未指定：** 先用中性电影语言，不把真人物理、真人表演尺度或真人镜头语法当成唯一默认；只有媒介会改变语法（真人 vs 动画、二维 vs 三维）且用户没有交代时，问一次。
- **形式未指定：** 从交付物判断：一条可投放片、一段故事板、一集长视频、一支广告，默认值不同；不要把所有任务都写成“短片”。
- **导演模式未指定：** 从题材、参考与用途推断；写实、诗意、实验、商业、类型化、纪录片是不同组织方式，不是滤镜开关。
- **平台未指定：** 不虚构画幅、帧率、时长与分辨率；需要时单列适配，不反改创作稿。

## 4. 声音与文字

- **先判声音目的，再决定加不加：**
  - **音乐主导型：** MV、音乐视觉化、歌舞、明确要求卡点或节奏同步的任务，音乐是结构与剪辑的一部分；没有指定曲目时不擅自填一首具体歌，先给音乐类型、节拍与段落功能。
  - **声音设计主导型：** 恐怖、动作、拟音实验、强调身体与空间的任务，按意图组合环境声、效果声、音乐或静默；音乐不是必需品，也不是禁区。
  - **信息主导型：** 产品演示、教学、纪录片、说明视频，按信息清晰度决定是否配乐；旁白与字幕只在确实帮助理解且用户需要时加入，不用音乐替事实说话。
  - **未指定声音偏好的普通任务：** 不擅自加入与创作目标冲突的音乐、旁白和台词；环境声、动作声与静默按场景设计。没有音乐不等于没有声音。
- **字幕与画面文字：** 默认不额外添加；用户明确要求的标题、产品信息、说明文字、歌词或字幕按其范围加入，不能用「默认无」当作拒绝用户要求的理由。
- **原著必要内心声或叙述：** 保留其原句与载体，不改成新增旁白、字幕或对白。

## 5. 时长、镜头与特效

- **时长与时间表达。** 默认事件编号与精确时间例外见[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。 不设统一 4～6 秒；由形式、平台、信息密度、表演与动作连续性决定。用户给总长就核对容量，没给就不估总长。
- **镜头：** 固定、手持、长镜、快切、环绕、POV、蒙太奇、长焦、广角是平等工具；按任务选择，不默认动态高于静态。
- **特效：** 强度不默认最大化；按事件后果、类型契约与注意力预算选择。克制与爆发都是导演工具。
- **物理：** 写实要承重；科幻／奇幻／武侠／动画先立本片规则，再让后果自洽；超现实可以违反现实物理，但不能违反自己刚建立的规则。

## 6. 谁覆盖谁

1. 用户明确要求与硬约束。
2. 任务契约的主导意图、成功标准与平台限制。
3. 媒介语法（二维、三维、定格、真人各自的规则）。
4. 类型惯例（恐怖、动作、广告等）。
5. 模块默认值与本页矩阵。

低层级不能覆盖高层级。发生冲突时，把裁决理由放复制块外，不把两套互相矛盾的规则同时塞进正文。
