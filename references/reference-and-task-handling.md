# 参考与任务处理

本页处理素材职责、锁帧、编辑与延长，不设生成平台、版本、时间轴精度、镜长、分段或提示词字数规则。创作设置由用户要求与故事需要决定。

<a id="katil-ref"></a>
## 参考职责

- 语义参考图只提取指定身份、造型、物品、布局与风格，不继承排版、白底和展示姿势；默认不把参考图直接当视频帧。
- 默认不附特效资产图或其生图词。用户实际提供这类图时才标为“特效参考图”，只提取指定效果的形态、材质、光色、粒子、接触与残留；图中人物、兵器与背景只作必要尺度／交互载体，不接管各自身份和布局。复制块内说明实际参考范围与动态作用，中英一致；没有图不写待生成占位，不虚构绑定。静态分区不是多次攻击，强度与因果继续按故事。
- 用户明确锁参考首尾帧时按其要求，仅对该锁定图删除互斥的禁入帧句；额外语义参考图仍保留自己的职责与禁入帧限制。先看实际图片核对人物姿态、持物与首动作；只有连接键时可继续写不依赖未知细节的稿，在块外说明起态兼容性待核，不假称已看图。
- 动作视频、白模、深度与故事板分别参考其动作、机位轨迹、布局或事件顺序，不连带复制角色、剧情、对白和音乐。多格板转成连续事件，不机械每格等长。
- 已有路径图的线、点或编号只表示实际指定的路线／航点顺序，外观图另管身份、材质与光色；控制线、白模、界面和标记不进入正式画面。只把可用路径编成正文，不抄软件点击步骤、示例素材键或未经确认的缺失路段，不默认索要额外路径图。
- 音频明确参考内容、音色还是节奏，不自动授权加BGM或替换指定台词。
- 实际素材连接键原样保留，中英不改名；文件存在不等于已经绑定，不编造@、Asset ID、URL或执行结果。

### 场景参考图的四维判断与“一减三留”

附场景参考图（或已绑定场景素材键）时，先分开判断，再组句；四项可以同时成立，不是四选一的状态机：

- **A 素材用途：** 无参考、语义场景参考、强制首帧、首尾帧、视频延长／编辑。用途只决定该图能否入帧和怎样承接，不自动指定机位。
- **B 摄影目标：** 固定机位、Zoom、Dolly／Tracking、旋转／摇镜、分镜切换、真一镜。
- **C 叙事任务：** 宏观尺度、空间关系、人物行动、细节、情绪、悬念、产品信息。
- **D 场景证据：** **K 已知**（图中可见）、**I 合理推断**（画外可延续，须标明是设计）、**U 未知**（看不到且无依据）。K 可约束；I 可作受限延展，但不得声称原图确认；U 不写成原图事实，也不凭空添加与现有空间冲突的地标。

**场景描写“一减三留”：**
- **一减（删减静态外观复述）：** 不在复制块内大段复述场景图已经可见的静态建筑雕花、墙壁颜色、远山形态或基础色调，避免抢占动作与运镜的注意力权重并诱导模型生成静止壁纸。
- **三留（只写三维交互信息）：** ① **留方位与轴线锚点**（借图内已有石阶、廊柱、拱桥等地标标定人物位置与运动方向）；② **留物理与光影反馈**（写清受力破坏、水花／尘土等当场介质位移，以及环境光源对人物的实时映照）；③ **留画外与纵深延伸**（机位转向、推进或切镜超出原图取景框时，写清沿同一空间逻辑延伸出的局部结构）。

**是否值得改变视角。** 只有同时满足以下条件，才建议换视角、局部起幅或真实机位位移：有相关场景参考；任务确需换视角、探索空间或真实机位位移；素材模式允许；画面有可描述的空间依据。否则保持用户构图，人物动作、光影、天气、声音仍可发展。用户指定固定机位、纯 Zoom、真一镜或锁首帧时，防锁死建议不得反改这些要求。

- **SR-A 首镜与起幅。** 从图中提取地标、方位、材质、光色与环境状态；不把原图静态机位默认为全片唯一视角。首镜由用户锁定条件与叙事任务决定，可大远景、全景、中景、局部近景或特写。只有任务确需探索空间、无锁帧限制且变化有图中或合理空间依据时，才局部起幅、换角度或穿行；不得为防锁死强行缩小景别、改用户首帧或加无意义切镜。
- **SR-B 真实位移。** 真实 Dolly／Tracking／弧形平移要结合图中已存在或按画外逻辑可合理设计的空间关系，优先写遮挡顺序、相对角度、近远景视差、地面透视、主体与地标距离、逐渐显露。不要求所有镜头都有前景，不强制前景滑出。缺纵深时保留简洁路径并说明可观察性有限，不凭空加柱子、树木或建筑伪造三维。纯 Zoom、固定机位、二维平面运动或风格化表达，不改成真实三维平移。
- **SR-C 锁帧承接。** 锁首帧时首帧按图承接，只删除针对该图的互斥禁入句，额外语义图仍保留职责。之后是否移动、何时改变景别或切镜，由用户要求与导演事件决定；可以先固定构图完成表演、光影或氛围变化，再在适合的动作节点展开。真一镜用连续路径；多镜切镜要有新观察任务与空间连续依据。不得为证明破框强制立即移动、立即硬切或大幅遮挡。
- **SR-D 相邻镜头。** 有场景图的多镜保持必要空间一致，但不要求每相邻两镜都换角度和景别。只有切镜服务新的观察任务时才变化；反应、强调、静态对话、对称、重复构图、长镜内部推进，可保留相同地标或景别。禁止无叙事目的地复制相同画面，也禁止为变镜破坏轴线、连续性或空间关系。
- **SR-E 锁死判定。** 锁死指用户需要动态探索或视角变化，而成片没有兑现；不以静态画面本身判失败。静态构图在悬疑、情绪、产品展示、远景尺度或用户指定固定机位中，可以是正确结果。

## 编辑与延长

编辑只改指定范围，保留其他有效内容及持续状态。延长分别记录原片范围、新增内容与目标整体，正文从已知尾态推进；不重播旧事件，不把多次生成拼接冒称真正一镜。没有真实尾帧／原片时按文字尾态继续，不称接缝已经验证。

总时长、用户及母稿锁定的镜长与时间戳、帧率、画幅、摄影与特效按创作稿保留；时间表达与局部返修沿用[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。实际提交若受工具约束，单独列出限制及适配方案；用户未授权不得删镜、取整、压缩台词、改时长或弱化效果来迎合工具。完整创作稿不因执行方案而被覆盖。

只要提示词不触发上传、付费调用或媒体生成；明确要实际成片时再使用对应可用工具，实际查看产物后核对执行结果。

## 参考意图与实际入口

明确模型适配时按[通用适配](model-adaptation.md)核对当前渠道的Reference／Keyframe／Edit／Extend机制；这些意图不是所有平台必有的同名按钮。某入口强制上传图为首帧，而用户同时禁止该图入帧时，当前组合冲突，不能用提示词消除真实机制。混用锁帧和语义参考的支持逐渠道核验，不套用另一平台的能力。

音频素材分别指定内容、音色或节奏，视频参考分别指定动作、机位、空间或风格；不连带复制未授权人物、背景、对白和音乐。参数值与模式限制只在命中模型的能力档案维护，本页不重复数字；实际图片／前片不可见时不认证构图、身份或尾态吻合。
