# 参考与任务处理

本页处理素材职责、锁帧、编辑与延长，不设生成平台、版本、时间轴精度、镜长、分段或提示词字数规则。创作设置由用户要求与故事需要决定。

<a id="katil-ref"></a>
## 参考职责

- 语义参考图只提取指定身份、造型、物品、布局与风格，不继承排版、白底和展示姿势；默认不把参考图直接当视频帧。
- 默认不附特效资产图或其生图词。用户实际提供这类图时才标为“特效参考图”，只提取指定效果的形态、材质、光色、粒子、接触与残留；图中人物、兵器与背景只作必要尺度／交互载体，不接管各自身份和布局。复制块内说明实际参考范围与动态作用，中英一致；没有图不写待生成占位，不虚构绑定。静态分区不是多次攻击，强度与因果继续按故事。
- 用户明确锁参考首尾帧时按其要求，仅对该锁定图删除互斥的禁入帧句；额外语义参考图仍保留自己的职责与禁入帧限制。先看实际图片核对人物姿态、持物与首动作；只有连接键时可继续写不依赖未知细节的稿，在块外说明起态兼容性待核，不假称已看图。
- 动作视频、白模、深度与故事板分别参考其动作、机位轨迹、布局或事件顺序，不连带复制角色、剧情、对白和音乐。多格板转成连续事件，不机械每格等长。
- 已有路径图的线、点或编号只表示实际指定的路线／航点顺序，外观图另管身份、材质与光色；控制线、白模、界面和标记不进入正式画面。只把可用路径编成正文，不抄软件点击步骤、示例素材键或未经确认的缺失路段，不默认索要额外路径图。
- 音频明确参考内容、音色还是节奏，不自动授权加BGM或替换指定台词。
- 实际素材连接键原样保留，中英不改名；文件存在不等于已经绑定，不编造@、Asset ID、URL或执行结果。

## 编辑与延长

编辑只改指定范围，保留其他有效内容及持续状态。延长分别记录原片范围、新增内容与目标整体，正文从已知尾态推进；不重播旧事件，不把多次生成拼接冒称真正一镜。没有真实尾帧／原片时按文字尾态继续，不称接缝已经验证。

总时长、用户及母稿锁定的镜长与时间戳、帧率、画幅、摄影与特效按创作稿保留；时间表达与局部返修沿用[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。实际提交若受工具约束，单独列出限制及适配方案；用户未授权不得删镜、取整、压缩台词、改时长或弱化效果来迎合工具。完整创作稿不因执行方案而被覆盖。

只要提示词不触发上传、付费调用或媒体生成；明确要实际成片时再使用对应可用工具，实际查看产物后核对执行结果。

## 参考意图与实际入口

明确模型适配时按[通用适配](model-adaptation.md)核对当前渠道的Reference／Keyframe／Edit／Extend机制；这些意图不是所有平台必有的同名按钮。某入口强制上传图为首帧，而用户同时禁止该图入帧时，当前组合冲突，不能用提示词消除真实机制。混用锁帧和语义参考的支持逐渠道核验，不套用另一平台的能力。

音频素材分别指定内容、音色或节奏，视频参考分别指定动作、机位、空间或风格；不连带复制未授权人物、背景、对白和音乐。参数值与模式限制只在命中模型的能力档案维护，本页不重复数字；实际图片／前片不可见时不认证构图、身份或尾态吻合。
