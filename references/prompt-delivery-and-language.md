# 完整复制块与双语交付

本页维护交付格式的详细规则；其他页面涉及同一规则时，若措辞重复，以本页为准。提示词保持平台无关；总时长、帧率、画幅与正文形式按用户要求及已确认创作设置，不借工具默认值补填或改写。

时间表达按[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)裁决。普通创作与模型执行稿默认按无时间码事件序，给定全片及分段时长写入相应视频块并核容量，未给总长按事件推进。用户及母稿锁定的精确时序保留；精确同步、已确认编辑窗口、重叠换算与结构化时间字段只在必要范围使用。局部返修沿原时序，明确去时码则重编并核容量。母稿转译时派生执行稿，保留来源及用户硬要求。

## 交付范围

完整创作默认给**角色图提示词、场景图提示词、视频提示词**，按本次实际需要补全或复用。**默认不提供特效资产图及其生图提示词**，不列准备清单、不追问是否需要；绚丽、宏大特效直接在视频正文内设计。只有用户本轮明确要求特效图片时，才按[资产专题](asset-prompts.md)交付。仅返修／续段不重给未改资产；用户明确只要正文、单语或某一类时，按其范围交付，不再补另一语言或其他类别。

人物设定图按[资产专题](asset-prompts.md)默认交付同一张三视图＋面部特写＋既定武器特写组合图（若用户针对特定视频平台要求拆分单人正视图以防多主体干扰，则按需提供拆分版）。

默认每个实际交付的图片提示词中文在前、英文在后；每个视频段也中文在前、完整等义英文在后。用户明确只要单语或某一范围时，只交付该范围语言，不再补另一种。**每段每种语言只有一个完整、纯净、可直接复制进视频生成框的正向提示词块**。两种语言任选一种提交，不要求合并。

## 视频正文开头：参考声明与锁帧

先判参考模式，三种状态写法不同：

| 参考模式 | 复制块开头怎么写 |
| --- | --- |
| 无参考图 | 不写任何参考图声明，也不写「如有参考图……」的条件句；正文直接进入画面。 |
| 普通参考图 | 声明只提取指定身份、造型、物品、空间布局和风格重构动态画面，参考图不得直接成为任一视频帧。 |
| 明确锁定首尾帧 | 按用户指定写实际锁帧承接（哪张图对应首帧或尾帧、怎样接首动作或尾态），删除与锁帧互斥的禁入帧句；其余参考职责仍按普通参考图约束。 |

普通参考图的中文可写：「只提取指定身份、造型、物品、空间布局和风格重构动态画面，参考图不得直接成为任一视频帧。」英文可写：「Use only the specified identities, appearances, objects, spatial layouts and styles to reconstruct a dynamic scene; do not use the reference images as any video frame.」多张图按职责分开写（角色、武器、场景、美术风格、动作或机位参考），不合并成一句笼统的「参考图」；仅实际提供特效参考图时说明其真实名称、编号与职责，没有的素材不写占位。

设定板上的文字、边框、多视图与展示姿势不进入动态画面；切镜不因参考图复原武器、服装与战损；未经用户要求不把参考图变成静态插帧。用户只要局部替换时按范围交付，不强行附完整开头。

持物连续原则融入首段起态或动作描写：依剧情连续换手、放置、收起与取用；原著、明确手别与唯一物品数量优先，不把本段已锁定的右手剑写成“自由换手”。

## 每个视频复制块包含什么（正向画面编码原则）

依次自然串接：**必要参考与媒介起态 → 跨段承接（若有前段）→ 核心事件、特效与观察路径 → 准确尾态 → 现场声音与纯净画面锚点**。默认按事件编号推进，编号后同一行直接接画面描述。多镜用 `分镜01` / `Shot 01`，真一镜用 `镜内阶段01` / `Phase 01`，静态故事板用 `第01格` / `Panel 01`。抽象章节名和内部表单栏目放块外，用户指定其他形式时按其要求。

- **参考与起态：** 只写实际素材和稳定称谓；未绑定用自然语言描述，已绑定连接键如 `@图片1` 在中英文原样保留。没有特效图就不列 FX 图编号或“图待生成”占位，直接描述效果。
- **信息密度与容量：** 先检查需要按顺序理解的事件、必须观察的变化及可并发的反馈；连续招式和协同动作按因果链处理，不按攻击次数机械计数。去掉重复设定、空洞套话与本轮新增的过载，不删必要台词、人物、武器、能力、运镜或尾态。没有固定字数、镜数、回合数或每秒动作公式；模型限制须单列适配并保留完整创作稿。
- **跨段承接（区分连续动作接续与叙事转场）：**
  有前段时，在本段复制块首句自然写明承接关系，**不在复制块内插入 `入段转场｜前段→本段` 等工程表单标题**：
  - **动作未完待续时（同相位承接）：** 前段结尾保留一个清晰的未完成动势、位置与运动方向，下一段首句直接从同一位置、方向与动作后续相位接续推进；
  - **段落完整收束、情绪停顿或有意跳切时：** 按剧本需要完成余波停顿、呼吸留白或场景／时间跳切，在下一段首句建立新阶段的起态与空间锚点，不强制每段结尾都悬停在半截动作上。
- **事件、观察与信息主次：** 按先后写清谁做什么、作用到哪里、对方怎样变化和镜头怎样看见。每个观察阶段围绕明确的主导视觉重心组织（时长由任务、镜头容量与信息密度共同决定，不固定 4～6 秒；双人连携合击或连续快切归入同一推进链条，不杂糅无关副线）；真一镜写连续阶段，不标成独立切镜。
- **自然动作表述：** 为便于读者理解画面，**复制块正文优先将“不要什么”改写为直接描述“画面实际发生什么”**（固定参考声明、声音锚点中的否定句除外）：
  - 忌写“不另切正反打” → 改写为“同一连续镜头内保持两人同框完成对话与视线交锋”；
  - 忌写“没有重打上一击、不默认击飞或镜头停格” → 改写为“顺切出方向连续回收长刃，对手后脚滑退半步稳住重心，摄影机保持匀速跟移”；
  - 确需平台级反向提示词（Negative Prompt）且当前入口确有独立负向字段时，可单列在复制块外部供用户填入该字段，不混入正向叙事句；固定参考声明、声音锚点中的否定句不视为平台级反向提示词，保留在块内。
- **尾态与声音收束：** 按本段需要交代人物最终位置、朝向、持物手别、伤势与环境残留。声音使用与本场吻合的具体来源；明确静音时全段无声。未经要求不擅自加入音乐、字幕、画面文字与额外旁白；音乐主导、信息主导任务按作品目的决定（见[默认矩阵](defaults-and-medium.md)）；明确静音时全段无声，原著必要内心声／叙述保留载体，不机械加入兵器声、风声或对白。

剧情所需的时长、画幅、帧率、摄影等创作设置完整融入复制块。素材准备、接口配置说明、来源映射、时间编排方式的解释与设计理由放块外。视频块内直接呈现给定总长、画面与声音事件及必要局部时点；“以无时间码分镜推进”“无分镜秒数”“其余按事件自然推进”等写作说明放在块外。

## 关键事件与终幕

写正文前，按任务需要组织概念、事件、因果、观察证据和时间／状态；不把事件表、模块标签、检测评分贴进复制块。用户明确要求决定性的终结时，检查前置条件、攻击端到达、必要的关键变化、直接结果与间接余波；可以同镜并行，不擅加攻击或延长收束。全程高速不自动加英雄摆拍；安静、悬疑、留白与有意不揭示服从原意。

**成稿交付前，执行[镜头执行契约](shot-execution-contract.md)的“容量与交付前返修”。** 动作任务并查[动作编排](action-and-shot-compiler.md)的必要因果、手脚与支点转换；多种强效果并存时按[特效与受创](effects-and-damage.md)组织主次。检查发现的过载或状态冲突须先修正文，不能只在内部写“注意容量”而原样交付。用户的速度、强度、媒介、必经事件和结局均参与复核；返修不能悄悄把强特效、高密度或多次异变降级。检查结论不塞入复制块，也不冒充视频验证。

## 导演推演与生成正文分开

内部推演攻击、防守、剩余威胁、端态、受力和效果候选；世界坐标、罗盘方位与米数按空间模式处理：S1／S3 只用于内部建图与投影，正式复制块写屏幕左右、前中后景、朝向镜头／背向纵深和具象地标；S2 是给人看的世界空间说明，可写尺寸、坐标与方位，但要标明层级，不能与屏幕左右同句混写（见[空间坐标与动态越轴](spatial-coordinate-system.md)）。正文保留使当前事件成立且画面鲜明的部分。将抽象口号换成可见变化：不是“真实命中、反馈强烈”，而是盾缘受压后腕肘内折、后脚失撑，攻击者顺阻力回收；不是“史诗粒子拉满”，而是本场主形体、尺度、展开和对战局通路的作用。

用有依赖的邻接句承接，不逐镜重复护栏栏目。具体视觉进入发生的镜头，中英文完全同事实。

## 翻译与台词

### 台词偏好：可问一次，不设强制等待关卡

原创视频尚未决定对白、且台词选择会影响情绪、节奏或人物表达时，可在创作起始简短询问一次：“这段需要给角色配台词吗？可以保持无台词、加入少量战斗短句，或由你提供原句。”

- 用户已明确无台词／纯动作：直接执行，不再问、不加入说出口的话。
- 已有原文或用户指定台词：按原句和载体使用，不重复询问，也不改写原文。
- 已明确授权自行编写台词：在授权范围直接编写，绑定说话者、目的、发声阶段与可读容量。
- 尚未决定且需直接交稿：暂按无新增对白处理，保留已有原句，后续按答复同步两版。

同意配台词后，短句服务已有剧情与动作，不为说话无故停战或超速念词。表情与嘴形匹配发声阶段。原文内心声和叙述不自动变成口头对白。

### 双语与原句锁死

默认先定同一份事件和状态，再写中文并作等义英文；单语交付时只写该语言并保持同一事件与状态。核对人物／镜头／资产编号、参考职责、视线与表情、身体应答、手别、数量、世界锚点、能力、先后、接触次数、秒数（若有）、损伤、尾态与声音。英文不能缩成梗概或另编动作；修改任一版同步另一版。

**指定台词原句、标点、说话者与载体锁定**，在英文提示词中仍保留同一原语言句子（如中文原句直接保留在英文版发声位置，说明说话阶段，不让角色改念英文译文或加双语字幕）。把原句放在实际发声阶段，其他位置不重复抄写避免角色念两遍。用户明确要翻译配音／字幕才调整。

## 容量与跨段承接

用户给总长就核对动作、发声和转场容量；不平均分镜，不固定两秒一节、十五秒一段或四镜一组。用户指定分段时，前段含准确尾态，后一段同语言复制块首句自然写入跨段承接（已有状态、画面／声音接法与首个新动作）。N 段有 N−1 个相邻边界，接未完成动作的后续相位，不重播前一击，不额外加时。

原文或硬事件在给定秒数内容不下时，先具体列出冲突，给出分段、缩小范围或调整时长的实际选项。

## 已登记模型的执行稿

明确目标模型时按[通用适配](model-adaptation.md)工作，不把指定模型一律转到Production。已有母稿保留来源；首轮只要执行稿可先立结构化骨架再直接成文，不默写另一份完整双语母稿。默认只展示执行稿；用户同时要两版才分别标用途，各段各语言各自完整复制块。原著、台词载体、精确时间线、声音与终点照原约束，不以简洁代替保真检查。

实际模式先于参考声明：锁帧仅解除对应锁定图自身的禁入帧句，额外语义图照各自职责处理。图像绑定或入口支持未知可继续写不依赖未知细节的稿，但不能将文案完成称提交已就绪。硬冲突和参数说明在块外；只要视频正文时不附工程表。文字衔接、平台延长和最终组装分别说明，不以剪接冒充一次原生真一镜。
