# 能力与全类型视效库 v2.0.0（KATIL 3.10.5 内置）：240种角色技能与影视视效

本库提供240条稳定编号的能力与影视视效卡，按24类（`C01—C24`）组织：
- **现实动作与战术（`C01—C07`，A001—A070）**：徒手控制、冷兵器格挡、跑酷机动、现代动作道具、潜行侦察、救援协作、运动竞速；
- **科幻装甲与能量（`C08—C12`，A071—A120）**：动力装甲、能量防护、无人机协同、磁电信号、生体仿生；
- **奇幻元素与规则（`C13—C20`，A121—A200）**：火热熔流、冰水流体、风土植物、雷光声波、重力动量、时空规则、幻象召唤、水墨纸艺；
- **非战斗全类型影视视效（`C21—C24`，A201—A240，V3.8.0 新增）**：
  - `C21` **商业微距与产品视效**（水油乳化、冰块入水冠冕、精密悬浮拆解、风洞流线、丝绸流波、液态金属、香氛焦斑、纳米脉冲、日晷光影、油脂拉花）；
  - `C22` **自然天象与宏观奇观**（极光折卷、深海荧光涡流、双月潮汐、穹顶圣光、四季延时枯荣、雷暴云墙、灰幕日食、荒原蜃景、星环流火、云海雾瀑）；
  - `C23` **心理梦境与超现实转场**（空间碎镜剥落、地面液化深潜、镜廊慢拍错位、走廊重力翻转、胶片烧穿闪回、轮廓风化散沙、雨滴悬停升空、瞳孔缩入换景、室内拉伸荒原、画布融化入实）；
  - `C24` **怪谈异变与诡异氛围**（烛火转绿逆影、纸人渗墨转睛、墙面潮痕漫延、红绸逆风悬铃、雪花屏显背影、井水倒影脱节、长廊逐灭逼近、石像裂纹渗泪、门缝黑水漫入、冥纸旋风空巷）。

每条卡片均包含机制、动作／过程、具体视觉表现（`vfx`）、限制／边界、镜头声音与持续尾态。

## 按需读取

- 先看[分类和编号索引](ability-library/index.md)，只读当前剧情或画面需要的分类。完整数据保存在单文件 `references/ability-library/abilities.json` 中。
- 当用户**只提供了想象的画面与视频类型，未描述具体特效细节**时，直接根据任务类型（动作／科幻／奇幻／广告／文戏转场／恐怖怪谈／自然空镜）从 `C01—C24` 检索匹配的视效母形，结合[特效与受创](effects-and-damage.md)融入分镜。需要按 15 类特效、六层或程序化生命周期检索时，再读 [FX Director](fx-director.md)与[程序化语法](procedural-fx-grammar.md)；本库不改写 240 张卡。
- 这些条目是可迁移的视觉与机制起点，不是世界通用权限，也不是白名单。库内无合适条目时可按当前规则继续创作，不能声称新方案已有稳定ID。

可用只读工具 `scripts/ability_library.py` 按ID、类别、世界类型、用途或关键词检索：

```text
python scripts/ability_library.py --category C21 --limit 5
python scripts/ability_library.py --category C23 C24 --limit 5
python scripts/ability_library.py --id A081 A201 A221 A231
python scripts/ability_library.py --world 科幻 --role 防御 --limit 3
python scripts/ability_library.py --query "微距 乳化" --limit 3
python scripts/ability_library.py --validate
```

## 选择顺序

1. **锁世界与类型边界。** `world=现实`只允许身体、实际器物、自然光学和真实材料反馈；`科幻`依赖虚构装置、工业科技与物理推演；`奇幻`依赖超自然规则或梦境怪谈设定。非战斗任务（广告、文戏、风光、心理、怪谈）优先选用 `C21—C24`，不强塞战斗爆炸或伤亡。
2. **锁功能角色。** 根据进攻、防御、机动、控制、感知、潜行、支援、救援或交互挑条目。
3. **核对条件。** 比较载体、范围、动作幅度、限制和人物现有状态；不因库里有召唤、分身或瞬移就自动给角色装备。
4. **融入当前画面。** 用本场人物、产品、地标、距离关系和光色改写。只选服务当前段落的少量机制，不把240条塞进一个提示词。
5. **回写状态。** 受力、材质变化、伤势、遗留物和环境异变进入下一镜与跨段转场。

## 机制与影像表现分开

卡片中的`mechanism`决定核心作用，`vfx`决定如何用画面看清该变化，`camera_sound`建议有效观看方式。锁定机制不等于锁死视觉上限；在用户要求幅度内，可按[特效与受创](effects-and-damage.md)调整主形体、体积、材质层与光色。

## 卡片字段

`id`为A001—A240，`category`为C01—C24，名称与编号稳定；`world`和`roles`用于筛选。`mechanism`写载体与作用，`action`写动作与过程，`vfx`写具体视觉形态与反馈，`counter_limit`写边界与限制，`camera_sound`写观看任务与声源，`residue`记录持续尾态，`signature`为内部四段式辨识键。
