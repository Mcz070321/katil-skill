# 关键状态与巨物尺度

在编写执行稿前填适用的工作表。每行指向实际分镜或镜内阶段，表格留在内部。阈值用于路由，镜数、时长、动作密度和特效幅度仍由任务决定。只为观众需要知道的变化安排可见证据，遵循原著揭示顺序、主动留白和既定视点。

## 1. 不可逆状态链

从用户指定的终态倒推前置条件，顺写 S0 到终态。按同一实体与手别核数量，记录断离物去向、仍具备的功能和继承状态。

| 状态与前置 | 触发与接触 | 可见变化前后 | 下一拍的入场条件 |
| --- | --- | --- | --- |
| S0 起态及持物 | 决定性动作之前 | 待变化对象、归属与数量可辨 | 前置条件已经建立 |
| S1…Sn 逐项写 | 攻击端到达、对象转化或功能改变 | 在同镜或衔接画面中能指出改变部位、离体物或残余能力 | 依赖此结果的下一动作从新状态起步 |

同一运动可包含数个可分辨的动作。只有先后依赖需要串行，能共同作证的动效可并发。崩解、雾化、传送光爆或遮挡式转场等会覆盖轮廓的效果，在必要结果可辨后接管画面。若变化本身就是转化，留出来源、过渡与终态的证据。

以双持鬼武者为例，先给两手各一柄可数弯刀。右臂带右刀离体，左手仍握左刀。左臂带左刀离体，两把刀沿各自路线继续运动。无臂躯干前扑；女主横斩其颈，头身拉开间隔，再由断口崩解。余波交代已建立的武器去向与女主最后的持刀姿态。

## 2. 巨物尺度梯

| 画面阶段 | 分镜或机位要交代的证据 |
| --- | --- |
| 分别成形 | 对象第一次建立时给可认轮廓、施放来源和同框尺度锚；作品明确要求遮蔽时，可用经授权的剪影或局部锚，待观众需要识别时补全。巨拳可见拳节、腕与前臂，巨剑可见柄、护手、刃身与尖。两物可分别成镜，但要共用可辨的场地参照。 |
| 会合与接触 | 在共同地标两侧建立来源、高度与力量轴线。接触画面保留双方受力边缘和同一个可指出的交点 C。需要切换时保持 C 和双方边缘可追踪。 |
| 峰值与恢复 | 从 C 所在构图派生冲击帧，按[特效与受创](effects-and-damage.md#冲击帧之后的结果承接)保留同一次接触的识别线索。恢复到同一接触及其后续相位，先给互相削切、压密、失效或稿定直接结果。 |
| 传播与拉远 | 爆发由 C 发出。沿明确方向后撤，追踪 C 或其物理后果。用共同地标缩小、同一圈云墙外推、云洞与星球弧面依序建立尺度。 |

示例中，祭坛断柱先对照巨拳完整外缘与巨剑刃长。接触镜保留拳节裂口与剑刃崩片。环形冲击从两者交点向外推云，沿同一环边退到大气弧面。首次建立和峰值是否展示全貌，服从明确指定的遮蔽、主观视点或构图；需要识别时补足轮廓。

## 3. 单段承载与可选分段

默认保留用户要求的交付形态。将状态或尺度表逐行放入现有段落，先给依赖链中的必要变化分配观看机会。空间不足时先合并可同时成立的反馈，压缩可选的重复交锋或装饰运镜，说明具体让位项。明确锁定单段、一镜、总长或事件时按锁定范围组织。如仍冲突，把需要用户决定的取舍单列。

分段作为用户允许时的执行选项。按可交接的变化结果切分，每段可承载一组因果相连且可辨的事件。用下表把预期和实际交接对齐。

| 前段可见尾态 | 交接画面与素材权限 | 后段从何起步 |
| --- | --- | --- |
| 主体和相对位置、手别和物件数量、已发生伤势、断离物落点、地标和视轴 | 先核前段实际尾画面是否满足必要状态。用户已授权且渠道支持时可锁实际尾帧或用延长模式，语义参考按其原职责使用。 | 在首句继承相同状态，从后续动作继续。若实际生成的尾态偏离要求，先修接点或用已有可用状态重编。 |

整片总长按最终呈现核算。接合处保留已发生的因果，合并有意共享的交接画面，继续下个动作。
