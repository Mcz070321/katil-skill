# 现实主义与广告：让真实可信，让产品被记住

现实主义、纪录片、社会题材、自然光摄影、品牌广告、产品短片与宣传片读本页。先分清维度：**现实主义是导演模式**，**广告是形式／用途**，题材可以是爱情、喜剧、科幻、家庭等；不要问“这是不是现实主义类型”，而要问“什么题材、什么媒介、什么形式、什么导演模式”。两者都要求**可信**，但“可信”的来源不同：现实主义靠不修饰的因果与细节，广告靠产品真实价值与清楚的视觉承诺。

## 1. 现实主义：先观察，再判断

- **人物有生活：** 手上有活、衣服有使用痕迹、房间有长期居住的杂乱；不是等待镜头的模特。
- **因果可信：** 人物按自己的处境行动，不按剧情方便行动；巧合可以有，但不能每次都靠巧合解决。
- **自然光与可用光：** 窗光、路灯、屏幕光、车间灯；保留光源方向与色温差异。不是“越暗越真实”，也不是“越灰越高级”。
- **不完美构图：** 允许遮挡、边缘裁切、焦点稍慢、机位不居中；但空间关系仍要能读懂。
- **声音：** 环境声、远处人声、机器声、脚步与布料；对白可以有重叠、口音、停顿与听不清的部分。不默认加钢琴配乐。
- **表演：** 克制、生活化、少设计感；不要求每句都字正腔圆，也不把沉默当深刻。
- **伦理：** 不把真实人物当奇观；不伪造苦难、疾病、贫困或暴力；涉及真实事件与人物时，区分事实、重现与创作。

### 纪录片式段落

- 先定是**观察、访谈、说明、再现**哪一种；不要把重现拍成事实。
- 访谈要有说话者、环境与目的；不要用无关 B-roll 盖掉回答。
- 让被摄者有自己的动作与停顿，不把每句话剪成金句。
- 额外旁白默认无；用户明确要求或原著必要叙述应按原载体处理，不替观众下结论。
- 事实、时间、地点、数字要可追溯；不确定就标不确定，不编造。

### 社会现实题材

- 写具体的人、具体的工作、具体的制度摩擦；不用抽象“底层”“人性”代替。
- 不把贫困、疾病、灾难拍成唯美奇观；不消费痛苦。
- 给人物选择与尊严，不只给苦难。
- 结尾不强行给出解决方案；可以开放，但要诚实。

## 2. 广告：一个想法，一个产品事实，一个可记住的画面

### 先定简报

| 字段 | 要确定 |
| --- | --- |
| 产品／品牌 | 到底是什么，卖点是什么，不能说什么 |
| 受众 | 谁看、在哪看、看多久 |
| 单一诉求 | 这支片只让观众记住的一件事 |
| 情绪 | 信任、欲望、好奇、安心、幽默、紧迫 |
| 形式 | 15／30／60 秒，横屏／竖屏，TVC／社交短片／产品演示 |
| 结尾 | 产品英雄镜头、口号、Logo、购买信息、无结尾 |
| 合规 | 功效、对比、代言、价格、免责声明 |

没有单一诉求的广告，通常只是堆画面。

### 结构

- **开场：** 按作品需要选择视觉问题、产品细节或情绪瞬间；不设固定秒数，不擅自添加画面文字或 Logo。
- **推进：** 用人物、场景或演示把产品带进真实使用；产品不是背景道具。
- **证明：** 质地、手感、声音、使用前后、成分、工艺、场景适配；用可看见的证据，不用形容词堆砌。
- **产品英雄镜头：** 产品外形、材质、关键结构、使用状态清楚；不要被人物或特效抢走。
- **结尾：** 品牌信息、口号、价格／渠道按简报；不自动加“改变世界”式大字。

### 产品与画面

- 产品外观、颜色、材质、比例、Logo 位置在全片一致；不凭空变形、增删配件。
- 按已知产品与简报可选择表现其质地、结构、操作或确有依据的使用反馈；不能因产品类别推定吸收、效果、温度、界面功能或其他未给事实。
- 人物使用产品的动作要正确；不为了好看做违反产品逻辑的动作。
- 产品可以拟人、可以奇幻，但前提是观众仍能认出产品与卖点。
- 不夸大功效、不伪造对比、不暗示医疗效果；用户给的合规边界优先。已给产品现象和条件应照实表达，不能擅自添加搅拌、加热、特殊原料等可能改变其作用条件的操作；条件不明确就保持中性，不把演示选择当作产品事实。

### 声音与音乐

- 产品声音（开盖、按键、拉链、倒水、咬下）是记忆点；不要全被音乐盖掉。
- 背景音乐默认无；用户明确要求时按品牌与场景选择。
- 额外旁白默认无；用户明确要求时可写得具体、有说话者，不添虚假功效。

## 3. 现实主义与广告的交叉

- 纪实风格广告：保留真实场景与人物，但产品出现要有叙事理由。
- 品牌纪录片：真实人物为主，产品为辅；不要写成加长版 TVC。
- 公益广告：事实准确，情绪克制，不消费受害者；给出可执行的行动信息。
- 政治／社会宣传：区分创作与宣传；不伪造民意、数据或现场。

## 4. 常见错误

- 现实主义：把画面调成灰蓝、 handheld 乱晃，就以为真实。
- 现实主义：人物为了剧情做出不符合处境的选择。
- 纪录片：用音乐与剪辑替观众下结论，事实却被剪掉。
- 广告：产品只在最后 2 秒出现，前面全是无关剧情。
- 广告：卖点太多，观众一个都记不住。
- 广告：产品外观在镜头间变化，Logo 时有时无。
- 广告：用“高级感”掩盖没有产品证据。
- 广告：把女性、少数群体、老人、儿童当纯符号使用。

**检查：现实主义——去掉配乐与滤镜，人物还像在生活中吗？广告——去掉 Logo 与口号，观众还能说出产品的一个具体好处吗？**
