# 关键事件的镜头执行契约

当重要动作、物件变化、表演转折或信息揭示需要观众理解时，用本页检查文字中的事件与观察是否相互支持；只处理真正关键的时刻，不给每一镜强制填表。用户、原著事实、媒介与锁定的镜头／时序优先。内部检查留在正文之外。

## 根据任务选择适用字段

对当前关键时刻，选择真正有用的问题，不要求每项都有值：

| 字段 | 问题 |
| --- | --- |
| 目的 | 观众此刻需要理解、感受或暂时不知道什么？ |
| 压力或条件 | 人物、物件或信息面临什么已有条件？无威胁就不虚构威胁。 |
| 行动或变化 | 谁做了什么，或哪一项已设定状态发生变化？无回应、接触或攻击也可以构成事件。 |
| 接触与结果 | 确有接触时，它在哪里发生、引起什么可辨变化？未发生接触则不补造。 |
| 反馈 | 哪些身体、材料、环境、情绪、声音或关系变化与本事件有关？ |
| 观察依据 | 相应信息经由画面、声音、已有上下文或适用的后续揭示如何被理解？ |
| 下一状态 | 若后续要承接，位置、持物、状态、关系或未完成动作继承什么？ |

对作品要求理解的关键变化，按需核对**原因对象是否可辨 → 发生何种变化 → 为什么引出下一状态 → 后续是否真的利用或继承它**。假设观众没有读过提示词，所需关系是否仍有依据？依据可跨画面、声音、上下文或后续揭示，不强制特写、慢动作或逐项填表。

文字因果合理不等于观众必然能读懂：当作品要求明确展示格挡、切断、关键伤害或产品事实时，观察关系要让相应对象与变化有可辨依据。多轮连续快招可通过统一动势、位置和下一关键事件表达，决定性接触按需要保留更清楚的观察机会；不机械要求每次动作插镜、慢放或填写七项。

<a id="katil-witness"></a>
## 关键事件的最低可观察性

生成时长不足以展示全部细节时，先保留决定主要叙事结果的事件，再压缩装饰：

1. 威胁来源：观众要知道压力从哪来；
2. 关键攻防行为：谁主动、谁回应、用什么挡或打；
3. 决定性接触或状态变化：破防、断裂、命中、揭示、关系转折；
4. 直接后果：受伤、失位、物件变化、战局倾斜；
5. 必要的空间、声音与情绪收束：让人读懂发生在哪里、结果是什么。

非关键装饰性特写、重复视觉奇观、已经充分建立的场景说明可以压缩或合并。镜头数量不与质量直接挂钩，关键事件被看清比增加镜头更重要；压缩时先删重复，不删因果链上的前一环。

## 从已要求的终态倒推

用户要求明确结局、决定性事件或多个最终状态时，内部反查：**最终状态 → 直接结果 → 决定性行动 → 必要前置条件 → 可观察依据**。先列出用户要求兑现的终态，逐项找到承担它的事件和观察机会；明确展示、声音暗示与有意未知分别按作品要求处理。倒推是核对已有因果，不新增破防、反击、能力、死亡或战后定场；开放结尾只核对其指定终点。

再按正向顺序核对：哪些变化必须依次完成，哪些材料、声音、表演与环境反馈可并发，特效峰值或切镜是否占走必要结果的观察机会。不能把所有结果只挤进“最后全部完成”一句，也不能用时间码合计正确代替承载判断。不设固定终幕秒数，不要求每项独立成镜；返修顺序沿用下文，不删用户锁定项。

例如用户已要求“钩刃卡进旧裂缝、铃结暴露、唯一终斩、怪物完全消散、山体切开、主角战后状态”，先为三个终态找到观察机会，再回查同一次终斩、失位与裂缝来源。若尾态必须直接可见，声响不能独自替代画面；若要求抽象或开放结束，不把本例结果搬入。

## 隐藏、留白与视点

遮挡、画外动作、主观盲区、声音暗示、非线性剪辑和不可靠叙事均可成立。若作品需要观众最终理解该事实，安排与原著和导演意图相容的观察或后续依据；用户或故事有意不解释、不揭示时保留未知，不为达成“看见”强行补全。声音可以承担叙事信息；无声音、严格视点或固定机位时服从对应限制。

关键格挡需要可读时，可在合适的视点交代攻击端、阻挡关系和方向变化；断裂或受压的可读性依据动作与材质安排，后续保留武器状态；换位可通过连续路径或新镜中的共同地标重建；情感转折可以由表演、行动或原有台词承载。对实验或抽象影像，感受、节奏与被保留的未知本身也可能是目标。

## 容量与交付前返修

命中主入口的复杂终局条件时，先用[关键状态与巨物尺度](decisive-state-and-scale.md)分配可见变化与尺度参照，再做本节容量反查。

时间表达沿用[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。默认无时间码时，按串行变化、并发反馈、支点转换、对白及终态观察机会判断容量；删掉数字后仍须重查事件轻重。文戏和恐怖中承担叙事功能的停顿同样参与容量保护。

观察阶段按本作品的时间、形式和事件复杂度组织：明确必须依次完成的变化，与可以随同一动作并发的材料、声响及环境反馈。多项反馈无需拆成多镜；增加特写、环绕或停留仍可能增加观看负担。不得把招式数或某个固定秒数换算为模型普遍承载量。

对承载紧张的阶段，内部区分三类信息，不要求对每个简单镜头填表：

| 信息 | 必查问题 |
| --- | --- |
| 必须依次完成的变化 | 上一步何时完成、下一步如何开始，是否给取物、解缠、落地、判断或发声留了过程？ |
| 可以并发的反馈 | 墨迹、破片、声音、表情是否依附同一事件，能否同框表达而不另增停留？ |
| 必须被注意的线索 | 后续胜负或揭示依赖什么，当前景别、焦点、遮挡和持续时间是否让它可辨？ |

**交付门槛：** 不能以“都写到了”或“时间戳加起来正确”判通过；每个必要的先后变化须有承接，关键线索须有观察依据，同一时间的身体、物品及机位任务须相容。没有可靠证据时不承诺某模型能按该节奏执行。

发现过载或约束冲突，先在用户允许范围内返修，再交付：

1. 删除重复描述、重复展示和无功能停留，保留实际动作、特效演化与必要表演。
2. 调整未锁定的观看位置、焦点与摄影，让相容变化同框，或将反馈随动作并发；不以快切藏掉决定性变化。
3. 合并、替换或删除技能自行补全的次要事件和冗余因果条件，再检查相邻状态。用户已锁定的细节不自动变成可删项。
4. 仍无法兼顾时，只指出具体冲突及所需取舍；不擅自延时、分段、改变结局、降低速度／特效强度或删除指定异变。

返修后重查受影响阶段的起态、过程、关键观察和尾态。用户明确要求的高速密集动作、大范围特效、多次冲击帧、复杂调度和空间异变都属于创作目标；通过主次、方向与时序组织，不把降强度、减招数或只保留一个高潮写成通用解法。非动作任务按自己的信息与表演检查，不强加接触、破防或终结。

已明确要求决定性动作时，按事件本身检查是否需要破防条件、接触、结果与持续状态；可在同一观察阶段交叠，特效峰值不能抹掉任务要求辨认的变化。用户要求开放结尾或原著未发生反击时不擅加终结。

### 用户明确要求最终一击时

- 不能只有大面积能量爆发，而缺少决定性事件的可观察依据：谁打中谁、打在哪里、什么状态被打破。
- 不强制使用特写；中远景、连续长镜头、单镜推进同样可以交代终结。
- 终结造成的大范围破坏应继承同一次打击的动能与方向，不随机追加多次无关攻击。
- 余波时长服务作品目标；不能无依据地占用主要高潮时间，也不能为了让结尾显得完整而补一个新事件。
- 只在用户要求明确终结的任务中触发；纯抒情、实验、开放结尾与有意留白不加这一套。

<a id="katil-outcome-lock"></a>
### 结果发生后的尾段锁定

用户要求的决定性结果成立后，把结果发生点与实际结尾分开：结果点之后的尾段只承接直接余波、承受、环境沉降、站位与呼吸、视线或声音余响，或用户已明确要求的下一阶段；不再新开独立攻击、召唤、领域、增援、追逐目标或第二结局。不得用新巨物、新战场或新增支线替换已经分出胜负的双人主体；分镜节点更多、总长仍有余量，都不是重写尾段的理由。

反转、诈死、二次觉醒、幕后新敌或续章钩子属于条件项：只有用户明确要求，且前文已有触发、尾段写出可见因果与新状态时才成立；没有前置触发、只靠尾段追加翻盘，仍按新开事件处理。

已建立的多线可以继续未解决威胁，但不得切回已经结束的双人决斗再开一轮；群像收束要能指出哪条线仍在进行、哪条线已经结束。

交付前从结果发生点追到实际结尾，检查是否出现新的独立事件、主体替换或第二结局；胜负、直接后果与余波至少各有一项可辨，但不要求每项独立成镜。

本条只约束结果成立后的尾段，不限制结果发生前的多线并发、交叉剪辑、必要反击，也不限制用户指定的开放式结尾。

具体动作因果与身体资源检查见[动作编排](action-and-shot-compiler.md)，摄影见[导演运镜](camera-direction.md)，空间与视点见[空间描述](spatial-coordinate-system.md)和[视点与连续](viewpoint-and-continuity.md)。
