# 动画与故事板：用媒介自己的语法

二维动画、三维动画、定格、国漫、日漫、动画短片、混合媒介、故事板与长视频分镜读本页。先分清维度：**动画是媒介**（二维／三维／定格／混合媒介），**故事板是形式**（交付物），题材是爱情、恐怖、动作、喜剧等；不要问“这是不是动画类型”，而要问“什么题材、什么媒介、什么形式”。动画不是“给真人规则加滤镜”，它有自己的时间、形变、表演与镜头语法。

## 1. 先定媒介，不要先定画风

| 媒介 | 运动与时间 | 画面重点 | 不要默认 |
| --- | --- | --- | --- |
| 二维手绘／赛璐璐 | 姿势、关键帧、hold、smear、循环 | 轮廓、线条、色块、分层 | 把三维体积感硬套二维 |
| 二维有限动画 | 少帧、重复、定格感 | 构图、表演、符号化 | 以为少帧就是低成本 |
| 三维 CG | 连续插值、物理、摄像机 | 体积、材质、灯光、镜头 | 把二维夸张直接套写实模型 |
| 三渲二 | 三维运动＋二维着色 | 线条、色阶、阴影分区 | 线条与体积互相打架 |
| 定格 | 逐帧、材质、微抖 | 实体质感、光、手工痕迹 | 追求完全平滑 |
| 日式动画 | 有限帧、冲击帧、静止演技 | 构图、眼神、速度线、留白 | 每卡都高速作画 |
| 国漫／风格化 | 混合二维三维、水墨、工笔 | 材质与笔触、宏大空间 | 把“国风”当统一滤镜 |
| 实验动画 | 形变、抽象、节奏 | 运动本身、色彩、声音 | 用叙事完整性要求它 |

画风由故事、受众、媒介与制作条件决定；不默认“日漫”“皮克斯”“国风”中的任何一种。

## 2. 动画表演：姿势先于表情

- **关键姿势（key pose）：** 先定最能说明动作与关系的姿势；中间帧服务姿势之间的过渡，不是平均插值。
- **意图线：** 身体从哪到哪、重心在哪、动作的起点与终点清楚；观众先读到“要做什么”，再读到细节。
- **hold：** 定格不是偷懒；在情绪、冲击、反应时保持画面，让观众读信息。
- **smear／速度线：** 高速动作可以用形变、拖影、速度线；但要有方向与起止，不是糊成一团。
- **夸张：** 动画可以比真人更外化；夸张要有支点与重量，不违反本片建立的运动规则。
- **口型与台词：** 口型同步按语言与风格；不要求每个音素精确，但说话者、停顿与重音要可读。
- **眼神：** 动画眼睛是强信息点；不要每卡都大眼特写，按场景需要。

## 3. 二维与三维的镜头差异

- **二维：** 镜头运动常通过背景位移、分层视差、循环动画、构图变化实现；复杂环绕可以用背景滚动与角色转身组合，不必假装真实三维空间。
- **三维：** 真实摄像机、焦距、景深、体积光可用；但不要因为能转就每场环绕。
- **三渲二：** 先定线条在什么距离出现、阴影如何分阶、高光是否手绘；保持全片一致。
- **定格：** 尊重微抖与材质；灯光可以强烈，但不要求完全消除手工感。
- **混合：** 二维角色在三维空间、三维角色在二维背景，都要先定“谁服从谁的透视与光”。

## 4. 角色与场景一致性

- 角色设定板：正面／侧面／背面、面部特写、关键配饰与武器；二维加表情表与口型表，三维加模型与材质说明，定格加偶体与替换脸。
- 服装层次、发型轮廓、配色、体型比例在全片一致；变身／换装要有过程。
- 场景要有空间骨架与可走路径；二维背景不是一张贴图，要能支持角色走位与镜头运动。
- 光影方向在场景与角色之间一致；二维可以用色块概括，但不要无因换主光。

## 5. 故事板：先把空间与信息排清楚

故事板不是“每格画漂亮”，而是让制作与观众都能读懂：

- **每格一个观察时刻：** 主体位置、动作相位、视线方向、景别、机位高低、运动方向；不把多个阶段塞进一格。
- **屏幕方向：** 从左到右、从右到左、向纵深、向镜头；同一场保持方向逻辑，除非有意越轴。
- **空间锚点：** 门、窗、桌、柱、楼梯、街道尽头；切镜后保留至少一个共同地标。
- **信息主次：** 每格有一个主导信息；不要每格都塞满背景事件。
- **连续性：** 服装、道具、伤势、光源、时间、天气连续；跳时间要标清楚。
- **格数与画幅：** 按故事需要，不默认九宫格；用户指定格数、顺序、画幅时遵从。
- **文字：** 默认不把对白、格号、箭头烧进正式画面；需要时另做标注层。

### 从故事板到视频

- 静态故事板用 `第01格` / `Panel 01`，转视频时按观看任务组织为 `分镜01` / `Shot 01`，真一镜用 `镜内阶段01` / `Phase 01`。只提取构图、站位、动作职责或节奏；格框、编号、白底、排版不进入视频。定格与关键姿势的精确时间按[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。
- 真一镜故事板展示同一路径的关键阶段，不因为分格就授权切镜。
- 锁首尾帧时按用户要求处理，不能同时写“参考图不作为视频帧”的互斥句。

## 6. 长视频与系列

- 先定**序列／幕／集**的结构：每段有目标、阻力、转折与钩子；不把长视频写成十个短片的拼接。
- 建立连续性圣经：角色状态、服装、道具、地点、时间线、能力规则、已用镜头；跨段不重置。
- 每段结尾留一个可承接的状态或问题；不每段都重启世界。
- 回顾／前情提要只在用户要求或平台需要时加；不默认用旁白补剧情。
- 多主角线索要有主次与交汇点；不平均分配导致每条都浅。

## 7. 常见错误

- 把动画当“低幼”或“省成本”，删掉表演与空间设计。
- 二维硬套三维环绕，背景与角色透视打架。
- 三维硬套二维夸张，模型形变失控。
- 定格追求完全平滑，失去材质魅力。
- 故事板每格都特写，空间与动作读不出来。
- 分镜平均分配时长，高潮与过渡一样长。
- 长视频每段重新介绍人物与世界。
- 用“画风参考”代替具体的线条、色阶、材质与运动规则。

**检查：遮住颜色与细节，只看剪影与运动，还能读出角色在做什么、空间往哪走吗？**
