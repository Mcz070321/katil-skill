# 特效事件同步 · 动作、画面、环境、摄影与声音

> 权威范围：以“事件”为单位，检查动作、主体特效、次级特效、冲击、环境、光学、摄影机与声音是否同源、同序、同结果。
>
> 这是导演内部检查，不要求输出表格、JSON 或固定字段。声音的层次、授权、音乐与静默仍由 sound-and-rhythm.md 裁决；机制、受力、破坏、伤害与结果由 effects-and-damage.md 裁决；摄影机由 camera-direction.md 裁决。

## 1. 事件是同步单位

同步不是“每一帧都对上”，而是“同一个事件里的各条轨道不互相矛盾”。

一个事件至少包含：

- 发起：谁、什么动作、什么器物、什么条件。
- 过程：效果如何形成、沿什么路径、碰到什么。
- 接触：什么与什么接触，接触点在哪，方向如何。
- 结果：对象、材料、角色、环境发生了什么。
- 余波：如何衰减，留下什么，下一事件如何接上。

先定事件边界，再谈轨道。事件边界不清时，声音、光学、摄影机都会各自成立但整体错位。

## 2. 八条内部轨道

| 轨道 | 负责 | 必须与事件对齐 | 常见错误 |
| --- | --- | --- | --- |
| Action 动作 | 角色/器物的实际运动、发力、接触 | 动作方向、速度、接触点、收势 | 特效先于动作，或动作停止后特效仍前进 |
| Primary FX 主体特效 | 主导类别的主要形态与运动 | 来源、方向、尺度、生命周期 | 主体特效无来源，或抢走动作主体 |
| Secondary FX 次级特效 | 边缘、尾迹、碎屑、余波 | 服务哪个主体动作，何时出现/消失 | 次级过多，主次不分 |
| Impact 冲击 | 接触瞬间的形变、火花、气浪、震波、冲击帧 | 接触点、方向、承受者、反作用 | 只有光，没有受力与结果 |
| Environment 环境 | 地面、墙体、植被、空气、建筑的响应 | 冲击前沿到达时间、范围、残留 | 环境提前倒塌，或切镜后复原 |
| Optical 光学 | 光晕、折射、色散、曝光、景深、烟尘遮光 | 光源、介质、镜头、曝光恢复 | 无光源全屏泛光，遮住接触点 |
| Camera 摄影机 | 位置、运动、焦点、景别、震动 | 观看任务、事件尺度、主体可读 | 镜头运动制造未发生的位移，或持续抖动 |
| Audio 声音 | 接触声、材质声、环境声、空间、静默 | 接触、材质、距离、方向、相位 | 声音先于因果，或静默时仍有爆炸声 |

## 3. 接触簇

“接触簇”是同一瞬间的动作、特效、冲击、声音、环境响应组合。它是同步检查的核心。

### 3.1 顺序

1. 动作接近：武器/拳脚/身体沿路径接近目标；特效可以先行蓄能，但不能先产生结果。
2. 接触瞬间：形变、火花、气浪、冲击声、反作用在同一事件内发生；不要求精确到同一帧，但不能分成两个无关事件。
3. 结果展开：对象后退/凹陷/破裂，环境响应沿冲击前沿传播，声音随距离与空间延迟。
4. 衰减与残留：特效减弱，声音余响，环境留下痕迹，角色承受后果。

### 3.2 接触簇检查

- 接触点是否可见，或被合理遮挡后仍能理解。
- 方向是否一致：动作方向、特效方向、碎片方向、声音方向、摄影机运动方向。
- 承受者是否有反应：形变、后退、格挡、失衡、痛苦、呼吸变化。
- 反作用是否成立：攻击者是否停顿、反弹、被震退、武器震颤。
- 材质是否一致：金属火花、石尘、水花、血肉闷响不能互换。
- 环境是否在冲击到达后响应，而不是提前。
- 声音是否与接触、材质、距离、空间相符。
- 摄影机是否在接触瞬间保留可读性，而不是用抖动/模糊掩盖。

### 3.3 时间码与非时间码

- 默认无时间码事件序：用“先、随后、同时、在……之后”表达因果，不强制秒数。
- 用户要求锁定秒轴时，才写具体时间；仍要保留事件顺序与因果。
- 高速动作可以用“同一接触簇”表达，不必逐帧拆解；但关键接触、结果与余波不能省。
- 慢动作可以拉长接触瞬间，但声音、环境与摄影反应也要按同一时间尺度处理。

## 4. 环境响应前沿

环境不是背景板，也不是延迟播放的特效。

- 冲击前沿从接触点/落点向外传播；不同介质速度不同：地面震动快，尘土慢，碎片更慢。
- 环境响应范围受能量、介质、遮挡影响；不能全场景同时响应。
- 环境响应可以有延迟，但延迟要有传播路径与时间感。
- 环境响应不应先于冲击到达；除非是预兆（风先到、尘先扬），且预兆本身有来源。
- 环境响应结束后留下残留：尘、裂纹、水渍、焦痕、倒伏的草。
- 切镜后环境状态保留；不能因为换镜就恢复原状。

## 5. 摄影机同步

摄影机是观察者，不是事件制造者。

- 镜头运动必须有事件动机：跟随动作、拉开揭示规模、移焦到接触点、震动回应冲击。
- 镜头不能制造画面中未发生的位移；角色没动，镜头推近不等于角色前进。
- 冲击震动应短促、有方向、有恢复；持续抖动会让观众失去空间。
- 关键接触点尽量保留在画面内；若必须出画，用声音、反应或下一镜承接。
- 焦点转移要有动机：从武器到眼睛、从接触点到环境后果、从前景到远景。
- 曝光响应要跟随光源事件，恢复后颜色与动作相位连续。
- 慢动作、抽帧、变速不改变事件因果；只是改变观看时间。

## 6. 声音映射

声音由 SOUND 权威授权；本专题只检查声音是否与事件同源。

| 事件/效果 | 候选声音 | 必须匹配 |
| --- | --- | --- |
| 粒子喷发/火星 | 细碎爆裂、嘶嘶、轻微噼啪 | 密度、速度、材质、距离 |
| 能量蓄积 | 低频上升、电流嗡鸣、空气压缩 | 蓄能时长、来源方向、释放前静默 |
| 能量释放 | 短促爆响、低频冲击、余响 | 释放方向、规模、空间 |
| 金属碰撞 | 高频撞击、金属余振、摩擦 | 金属种类、厚度、接触角度 |
| 建筑断裂 | 低频开裂、石块摩擦、坍塌轰鸣 | 材料、结构、坍塌顺序 |
| 流体 | 水流、粘稠流动、飞溅、沸腾 | 粘度、速度、表面、容器 |
| 空间扭曲 | 低频拉扯、相位偏移、耳鸣、静默 | 扭曲范围、对象、恢复 |
| 冲击后静默 | 耳鸣、闷响、呼吸、远处碎片 | 角色主观、距离、持续时间 |

规则：

- 声音与接触、材质、距离、空间、相位相符；不能所有命中都用同一种爆炸声。
- 声音可以先入或后出，但要有叙事动机；不能无来源地提前揭示结果。
- 静默是声音设计，不是“没有声音”；静默时关闭所有声音，包括环境与动作声，除非主观保留。
- 无 BGM 时仍可保留环境声、动作 Foley、接触声；不要把所有声音都删掉。
- 声音不能新增画面没有的事件；听到爆炸，画面或叙事必须支持爆炸发生。
- 声音授权归 SOUND；本专题不新增声音、不改变音乐/静默决策。

## 7. 跨镜状态

切镜后，八条轨道都要承接上一镜末端状态。

- Action：动作相位、站位、武器位置、呼吸。
- Primary FX：持续状态、方向、强度、边界。
- Secondary FX：尾迹、碎片、余波是否还在。
- Impact：接触点、伤势、形变、破坏。
- Environment：烟尘、火光、水渍、裂纹、倒伏。
- Optical：曝光、焦点、镜头污迹、光晕是否恢复。
- Camera：运动方向、速度、构图逻辑。
- Audio：持续声、余响、静默、空间回声。

规则：

- 切镜不重置特效、破坏、伤势、残留或声音状态。
- 遮挡不等于消失；画外效果仍可影响画内。
- 时间跳跃要有明确信号；没有信号时，默认连续。
- 新事件可以开始，但不能抹掉上一事件的结果；除非用户明确要求重置或修复。

## 8. 静默与音乐

- 静默用于强调接触、冲击、恐惧、失去、决断；不是默认背景。
- 静默前通常需要声音建立，静默后需要余响或呼吸承接；全程静默是另一种风格，需明确。
- 音乐不能代替接触声与材质声；有 BGM 时，关键 Foley 仍要可辨。
- 音乐节奏可以与动作/剪辑同步，但不能让观众误以为画面发生了未发生的接触。
- 声音的“大小”不等于事件的“强度”；近距离轻声可能比远处爆炸更压迫。

## 9. 检查清单

### P0 同步硬约束

- 关键命中/关键效果有来源与触发，不是无因出现。
- 接触点、方向、承受者、反作用可理解；没有只有光效没有结果。
- 声音不先于因果揭示结果，静默时没有残留爆炸声。
- 摄影机不制造未发生的位移，不用持续抖动掩盖空间。
- 特效不新增未授权攻击、召唤、破坏、伤害或结局。
- 切镜不重置特效、破坏、伤势、残留与持续状态。
- 特效消散不写成环境修复、伤害痊愈或破坏复原。

### P1 叙事与可读性

- 接触簇的动作、主体特效、冲击、环境、光学、声音在同一事件内。
- 环境响应沿冲击前沿传播，有范围、延迟与残留。
- 光学有光源/介质动机，不遮关键接触点。
- 声音与材质、距离、空间、相位相符。
- 摄影机运动有事件动机，关键帧主体可读。
- 多镜状态连续，时间跳跃有信号。
- 风格与媒介一致，同步规则不破坏原有类型语法。

### P2 表现力

- 接触簇有节奏变化：蓄、发、停、余。
- 声音有层次：近/远、干/湿、实/虚。
- 环境响应有细节，但不抢主体。
- 静默使用有叙事重量，不是随意断声。
- 余波为下一镜提供叙事资产。
