# 叙事与表演：让事件改变人物

文戏、剧情片、爱情、人物关系、对白与混合类型中的表演段读本页。动作段里的“打之前为什么打、打完之后人变成什么”也读本页，但具体攻防交给[动作编排](action-and-shot-compiler.md)。

## 1. 先找这场戏的变化

一场戏不是“一个人说了一段话”，而是**某个人想要什么、遇到什么阻力、做了什么、关系或处境发生了什么变化**。写之前先填一张内部小表：

| 问题 | 例子 |
| --- | --- |
| 谁想要什么？ | 她想让他留下，但不愿先开口 |
| 什么挡住他？ | 他以为自己必须走；两人都不说真话 |
| 这场戏的转折是什么？ | 她把伞塞给他，等于承认自己在意 |
| 结束时什么变了？ | 他留下了伞，却没有追；关系从“未说”变成“错过” |
| 观众新知道什么？ | 她比他更勇敢；他更习惯被动 |

没有变化的场景可以存在，但必须有信息、气氛或人物侧面的新增；不能只是把已知信息换一种说法。

## 2. 结构：钩子、推进、转折、余波

- **钩子：** 开场给观众一个待解的问题、一个不寻常的动作或一个关系张力；不靠旁白解释。
- **推进：** 每一拍让人物做出选择，选择带来新信息或新阻力；不重复同一情绪。
- **转折：** 让观众以为的方向偏转一次；转折要有前面埋下的依据，不靠临时新设定。
- **余波：** 结束在变化后的状态，不自动加胜利摆拍、烟尘空场或新敌人。
- **伏笔与回收：** 一个物件、动作、台词可以在前段出现、后段变义；不要每件道具都赋予象征，也不要在结尾强行解释。

## 3. 表演：把情绪翻译成可看见的行为

不要写“她很悲伤”“他很愤怒”“气氛紧张”。写人物**为了什么目的、对什么刺激、做了什么可看见的动作**：

- **目标与动作：** 她想被挽留，却把伞塞给他；他想追，却只握紧伞柄。动作与目标相反，才有戏。
- **微表情：** 视线落在哪里、停留多久、什么时候移开；眉内／眉梢、嘴角、下颌、呼吸、吞咽、肩颈与手指的细小变化。只写镜头能看见的部位，不要求每镜五项齐全。
- **身体距离：** 靠近、停住、后退、绕过、挡住去路；距离变化比“深情对视”更可拍。
- **停顿与节奏：** 回答前的空白、说到一半的停住、手停在半空；停顿要有原因，不是拖时长。
- **听与反应：** 说话者不必每句独占镜头；听者的反应可以承载潜台词。但不要替听者擅自加原著没有的立场。
- **表演尺度：** 写实、文艺片更克制；喜剧、动画、舞台化类型可以更外化。按媒介调整，不把一种尺度当唯一正确。
- **连续性：** 眼神方向、手部任务、持物、坐姿、伤势、泪痕与呼吸在切镜后保持；情绪可以变化，物理状态不能无过程重置。

## 4. 对白：每句话都有说话者、目的与阶段

- 先定**谁对谁说、为什么现在说、说给谁听、说完想得到什么**；没有目的的台词删掉或改成动作。
- 允许潜台词：人物说 A，实际想要 B；但画面要给观众可追踪的线索，不能靠结尾解释。
- 台词长度要匹配发声容量与镜头时长；不靠极速朗读把长解释塞进短镜头。
- 对话可以重叠、打断、沉默、答非所问；按人物关系与场景节奏选择，不默认每句都完整。
- 旁白只在用户要求或原著必要叙述载体时使用；不把内心声自动变成口头台词，也不默认加解释性旁白。
- 原句、标点、说话者与载体锁定；翻译配音或字幕只在用户明确要求时做。

## 5. 爱情与亲密

- 用**距离、停顿、手部、视线与日常动作**表达关系，不靠慢镜、柔光、雨中共舞等现成浪漫符号堆叠。
- 亲密要有过程与同意：靠近前的犹豫、对方的后退或接受、触碰的停顿；不把强迫、跟踪或越界拍成浪漫。
- 冲突不必靠误会；可以是价值观、时机、责任、阶层、恐惧。误会可以有，但人物要像成年人一样处理信息。
- 结尾可以是在一起、错过、开放或告别；不自动加追车、机场奔跑或癌症反转。

## 6. 恐怖与悬疑的叙事接口

恐怖段落的氛围、未知感与惊吓节奏见[恐怖与悬疑](horror-and-suspense.md)。本页只提醒：恐怖人物也要有目标与行为逻辑，不能只靠“突然出现”推动；悬疑的信息释放要有公平线索，不靠隐瞒观众无法知道的事实。

## 7. 与动作、奇幻、广告混合

- **动作前：** 用最短篇幅建立“为什么必须打、输了会失去什么”；不写长篇身世。
- **动作中：** 人物性格通过选择体现（护人、逃、骗、留手、下死手），不靠台词喊口号。
- **动作后：** 给身体与关系余波；不自动切到胜利微笑。
- **奇幻／科幻：** 世界观信息跟着人物需求出现，不整段解释设定；能力使用要有代价或限制。
- **广告：** 人物 mini-story 服务产品，不要反过来让产品打断情感。

## 8. 常见错误

- 用情绪标签代替表演：“她崩溃地哭了”没有可拍的行为。
- 每场都靠吼、摔东西、下雨表达强度。
- 台词把人物已经知道的事重新解释给彼此听。
- 为一个反转临时加新设定，前面没有依据。
- 把爱情写成单方面凝视与跟踪，缺少对方的选择。
- 文戏里硬塞打斗、爆炸或追车，只因为“怕观众无聊”。
- 用慢镜、钢琴曲、雨声当情绪本身，人物却没有做任何选择。

**检查：删掉所有形容词后，观众还能从动作、视线、距离、台词与声音里读出这场戏发生了什么吗？**

需要自然天象空镜（极光、云瀑、丁达尔圣光）或心理梦境无缝转场（碎镜剥落、瞳孔换景、地面液化）时，可按需检索[能力与视效库 C22—C23](ability-library.md)。
