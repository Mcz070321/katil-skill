# 视频风格的选择与提示词转换

库含60种实用风格配方、10类，见[索引](style-library/index.md)；ID为S001—S060。每类六条只为检索管理，不是艺术种类上限。卡片区分造型与动作、材质、光色、摄影剪辑、效果声音和限制，并提供角色图、场景图、视频的中英风格片段。只读相关一类或几张；不把60卡全部塞进上下文或一个提示词。

## 选择与落地

1. **先遵从媒介。** 用户已说真人、日漫、CG、像素、黏土等就按该类细化，已有确认或授权代选直接延续。完全没有媒介信息且未授权才问一个关键问题。参考脸／服装的媒介不必决定整片。
2. **再看叙事任务。** 纪实观察、心理近景、商业展示、史诗尺度、情绪诗意、动作交锋需要的观看方法不同；同为CG也不统一为光滑游戏画面，同为日漫也不统一加战斗速度线。短片只取有用特征，不强加类型剧情。
3. **建立五项共用锚。** 造型／轮廓、材料／表面、光色、动作时间组织、镜头／效果。实际交付的角色图、场景图及视频共用这五项；设定板展示光与视频叙事光可以不同，但身份、结构、材料种类与色彩锚不能漂移。
4. **把风格片段融入实际设计。** 角色补具体外观与视图，场景补空间和路径，视频补表演／攻防、摄影及特效主形体、演化与反馈。默认不附特效资产图／生图词，用户本轮另要时再按同卡材质光色细化。每项实际交付默认中文＋完整等义英文；用户明确单语或某一范围时按该范围，不补另一种。库内片段不是完整故事，也不能替代实际资产提示词。
5. **检查时间与权限。** 风格节奏可写停连、关键姿势、连续插值或材质变化，未给秒数不强加帧率、顿帧时值、每镜长度或快切配额。音乐与字幕按用户要求及[默认矩阵](defaults-and-medium.md)判断；风格不会授权新增超能力、图像生成或发布。

## 把不同媒介的词分开

| 媒介／目标 | 优先描述 | 避免无条件加入 |
| --- | --- | --- |
| 真人剧情、广告、纪实 | 表演微变化，服装与道具真实受力，光源方向、曝光和适用的焦点转换 | 永远毛孔特写、浅景深、暗调、胶片噪点或器材参数 |
| 写实CG与实拍融合 | 体积、材质响应、接触阴影、反射与尺度；融合时匹配机位和受光 | “禁止CG”、强换真人脸、无限反光、所有材料同一塑料质感 |
| 风格化三维 | 形体比例、可控形变、阴影概括、轮廓与贴图笔触 | 用写实细节淹没造型，给每镜摄影胶片损伤 |
| 日式二维／其他二维 | 线条、色块、关键姿势、停连、分层视差和有原因的形变 | 真人毛孔、无差别次表面散射、每帧都强行匀速补间 |
| 水墨／水彩／绘画 | 笔触边缘、纸面／画布、干湿浓淡，形体与色层如何连续变化 | 每帧纹理随机重生，主角身份随笔触变化，摄影虚化遮掉构图 |
| 定格／实体材质 | 实体尺度、关节／接缝、手工表面、重心与帧间姿态，布景光 | 用断肢、换脸、道具乱长冒充手工感；误称必须同一低帧率 |
| 像素／矢量／动态图形 | 稳定网格／边缘、有限色板、姿态轮廓、图层和形变规则 | 无意义景深、颗粒叠加、矢量边缘抖动或每镜随机分辨率 |
| 混合媒介 | 明确主体／背景／特效各自媒介，遮挡、接触和转换路径 | 所有风格名堆叠、没有过渡就改脸／改地图、画风改变自动变成法术 |

这些是选用准则，用户明确的混搭或实验要求可以覆盖具体禁忌；仍保持主体与剧情可读。原电影资料的“皮肤、焦外、胶片模拟、反廉价化”等只在适用媒介中转换，不逐字强贴。

画风锚点与效果强度分开。同一种精密CG可有细微剑光，也可有遮天体积和巨型断层；按用户要的规模设计形态与明暗，而非把静态参考里的弱光当上限。保住身份靠位置、造型与主色连续，宏观镜头不要求和面部特写一样读清手指。强化表现不自动改变能力机制。

像素画统一的是**单个像素的显示尺寸与逻辑网格**，不是像素簇大小。像素簇是用于塑造脸、衣装与环境轮廓的像素组合，可以大小、形状各异；中英都避免写“统一大小／统一方形像素簇”或“consistently sized square pixel clusters”。逻辑网格与实际输出分辨率分开；没有给分辨率／画幅时，不把教学示例参数称作平台默认，需要代选则标为本稿设计选择。

## 混合、转换与库外扩展

混合先定主媒介和受限的辅层，例如三维角色／场景＋手绘接触效果，或真人主体＋二维思考图形；写明辅层何时出现、遮挡谁、怎样结束。不能用“真人＋日漫＋油画＋黏土”代替一致设计。

用户要求换风格时，先列不变项：事件、角色身份特征、服装结构、武器数量、持握手、世界锚点、时长和结局；再分别改造型、表面、光色、动作节奏和摄影／效果。需要身份更换或场景重设计必须来自用户要求，不能由风格标签暗中改变。

连续梦境或材质变换要设计可见连接：相同轮廓／动作相位保持，纸边转成布纤维或笔触沿既有形体出现；不可把随机画面闪切叫连续变形。真正一镜与严格POV仍适用。

库外风格沿用同一描述维度，必要时查用户指定参考，再说明可观察到的机制。按已有风格理解做原创配方，不声称复刻某影片全部工艺，也不保证某模型必然实现。研究来源和本文设计推断的界线见[学习资料](style-study-sources.md)。

## 只读检索

在本技能目录执行：

```powershell
python -X utf8 scripts/style_library.py --list-families
python -X utf8 scripts/style_library.py --id S032
python -X utf8 scripts/style_library.py --family F09 --query 毛毡
python -X utf8 scripts/style_library.py --query "stop motion" --limit 4
python -X utf8 scripts/style_library.py --id S041 --json
python -X utf8 scripts/style_library.py --validate
```

助手仅读取分类JSON，索引与阅读版由相同数据生成；检索不写文件、不执行媒体工具。指定ID、类或关键词没有结果时明确返回无匹配，不伪造卡片。图像用户自行生成；没有生成工具不影响提示词交付。
