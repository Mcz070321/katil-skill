# 动作视频验收：用同条件生成判断规则是否真的有效

无时间码稿按预期事件阶段与可见依据定位；真实视频评审记录实际观察秒数。提示词时序与成片观察记录分别评估，时间表达依据[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)。

本页是**动作与高速战斗专项**验收协议，不是通用验收；通用意图、叙事、人物、风格、时长与声音检查先读[通用验收](general-acceptance.md)。动作专项只在动作任务中加检，动作 P0 不用于文戏、广告、恐怖、爱情。

需要判断一次动作规则升级、版本 A/B、复杂空间调度或反复失败是否真的改善成片时读本页。本页只管**验收协议、记录与判定**；单条用户反馈的定位与局部修订见[反馈修订](feedback-repair.md)，文字设计检查见[战斗视觉精修](combat-visual-refinement.md)与[完整复制块](prompt-delivery-and-language.md)。

## 1. 先分清两种验收

| 层级 | 能回答 | 不能回答 |
| --- | --- | --- |
| **文字验收** | 正文是否写清动作、接触、方向、端点、地标与尾态；是否有结论词替代画面 | 模型实际能否生成、动作是否真的连贯、命中是否好看 |
| **视频验收** | 在固定模型与设置下，成片是否出现方向错误、人物漂移、参考图插帧、衔接断裂、命中反馈缺失 | 换模型、换素材、换时长后是否同样成立 |

文字验收通过不等于成片通过。没有实际生成并观看视频，只能报告“文字设计已改”，不能报告“成片已改善”“成功率提高”。

本页的 P0／P1 与记录格式不定义证据等级。对外声明按[证据等级与声明边界](evidence-and-claims.md)：文字验收属于 EV1，单次全片观察属于 EV2，同条件多次加独立盲评属于 EV3；生成用例在未观看前保持 PENDING_VIDEO。

## 2. 固定变量：先保证可比

同一轮 A/B 至少固定以下条件；缺一项就在记录里标明，不能假装同条件：

- 模型与版本、生成入口／模式；
- 输入素材：角色图、场景图、首尾帧、特效参考、素材绑定方式；
- 时长、画幅、分辨率、帧率、音频设置；
- 提示词：保留同题锁定的事件、动作顺序、台词、镜头限制与尾态；单变量测试其余条件尽可能一致，版本整包比较须记录摄影等差异；
- 种子（若模型开放）；不开放时固定提示词并重复生成；
- 参考强度、负向提示词、风格强度等全部参数；
- 生成次数与挑选规则：**先定次数，不挑最好的一条当结论**。

建议做一张测试卡，每轮复制填写：

```
日期：
被测版本：____　对照版本：____
模型／版本：
时长／画幅／分辨率／帧率：
参考素材：
种子（若有）：
生成次数：每个场景每版至少 3 次
本轮被测规则／规则包：____（要归因到单条规则时，另做单变量测试）
```

## 3. 测试集：至少覆盖三类空间

标准验收用 3 个场景，每个场景两版各生成 3 次；时间或预算不足时至少做 1 个场景两版各 2 次，并在结论里标“小样本”。

1. **地面双人攻防：** 左右站位明确、一次格挡、一次反击、一次命中反馈；检查攻击方向、人物身份、武器手别、接触与受力。
2. **高速环绕／双人换位：** 一次可见弧线越轴或交叉换位；检查越轴是否有过程、切后是否重锚、背景是否连续。
3. **巨物／立体空战：** 人类对巨物或空中多高度层交战；检查尺度参照、局部轴线、垂直越轴与人物是否漂移。
4. **可选参考图压力测试：** 多张角色／场景参考、锁首尾帧；检查参考图是否被当成静态帧插入、身份是否串换。

每个场景的已定开头与结尾状态保持一致；单变量比较只改被测规则并记录其他影响因素。比较两个版本各自生成的完整方案时，摄影设计可不同但不得违反锁定镜头与事件，所有差异需记录，结论只能归于版本包而非某条规则。

## 4. 观察指标：先记 P0，再记 P1／P2

### 先建立要求与证据的对应

取得实际提交的提示词后，将用户硬要求、已定关键事件与技能自行补全区分，再记录需要验收的项目。未取得的素材、参数及原稿标未知，不拿记忆中的另一版替代。

| 要求／事件 | 预期时间与可见依据 | 实际位置与观察 | 证据类型 | 判定 |
| --- | --- | --- | --- | --- |
| 例如同一次终斩贯出并释放剑气 | 刀路、目标、接触与后续相位 | 填实际所见，不照抄提示词当结果 | 原速视频／逐帧／抽帧／音轨／用户报告 | 符合／偏离／未知／不适用 |

检查事件是否在、顺序与方向是否一致、状态是否延续、指定材质及冲击帧是否真的可辨；“有大特效”不等于“指定水墨或冲击帧已兑现”。强度与艺术表达按任务验收，不默认越少越好。

只有抽帧时，可记录所见接触、造型和有限时点变化，不能证明原速流畅或无依据停滞；未覆盖全部原始帧不能断言极短冲击帧不存在。没有实际听到且能与画面对应的音轨，不判音画同步。具备哪些证据就结论到哪一层；未知项不填通过，也不直接算失败。

分开记录文字设计缺陷与本次输出偏差：原稿自身的时序／资源冲突可判文本问题；文字已清楚指定而视频偏离时，先记录未遵循，根因仍需核对素材、模式、参数与重复生成。单条旧成片只用于诊断，不作为新规则改善或整版通过的证据。

程序验收的媒体与评审记录格式见[回归运行器说明](../tests/README.md)：`evidence_status` 与 `review_status` 分开报告。有效视频流、证据去重和外部逐条全片评审均成立后才可导入外部 PASS；`reviewed=true`、文件后缀或结构通过不能替代。程序不能认证评审身份、实际观看或生成来源。

### P0：一票否决

出现任一项，该条成片判失败；不要用“整体好看”抵消。

- 攻击命中错误一侧、错误目标，或攻击方向与正文相反；
- 人物身份／服装／武器串换，A 的动作接到 B 身上；
- 在禁止参考图直接入帧的任务中，参考图被当作静态帧、拼贴或分镜板插入；明确锁定首尾帧时按用户要求判定；
- 人物／巨物无过程瞬移，切镜后换地图、换楼层或换站位；
- 未授权的武器／肢体瞬间换手、穿模到不可读；或任务要求直接可见的决定性接触完全缺失，以致结果无法判断。

### P1：明显缺陷

- 越轴无可见过程，或切后左右关系反转却无地标重锚；
- 非决定性接触缺乏必要受力、攻方反作用或战局残留（按事件需要检查）；决定性事件无法理解时按 P0 检查；
- 上一击未回收就接下一击，或切后重演同一击；
- 人物身份／位置／朝向明显漂移，但尚未到串换程度；
- 共同地标丢失，背景建筑／地形在切镜后改变；
- 参考图风格或构图明显污染成片，但未直接插帧。

### P2：细节瑕疵

手指、碎片、纹理、光影、衣摆、轻微穿模等不影响攻防阅读的问题。P2 单独记录，不与 P0／P1 混算。

### 补充的动作与视觉缺陷

对任务必需且约定应能辨认的决定性事件，完全缺失或关键接触无法判断导致结果无法理解，可记动作 P0；关键动作已发生但路径不清、受力不足、效果遮盖高潮，或明确要求持续交锋却出现无依据停滞，可记动作 P1。主要指定媒介显著退化使美术目标不成立可记视觉 P1。分级按任务与实际证据，不把故意留白、画外事件、非动作静止或授权锁定参考帧误判为失败；P0/P1 与用户目标一并记录。

### 有效运动与停滞

**有效运动不等于画面像素在动。** 摄影机摇移、粒子飘散、衣料抖动只说明画面有变化，不说明角色在交锋。

有效运动可来自：人物位移与站位改变；主动攻击与施压；有目的的闪避、格挡、卸力与反击；利用环境换位或重新取得优势；武器与身体的接触、受力与反作用；能力驱动下持续改变战局的行动。

短暂静止也可以成立：诱敌、屏息、恐怖压迫、情绪表演、力量蓄势与反转都需要停顿。判断看它是否有目的、是否改变观众理解或战局，不把「静止」本身当缺陷。

对明确要求高速连续打斗的任务，逐阶段检查是否仍有：**主动目标 → 行动 → 对手反应 → 战局变化**。若某阶段只有摆姿势、绕行运镜与特效扩散，标记为「可能的无效运动阶段」，再结合原速观看确认；不凭抽帧或单帧构图下结论。

### 尾段检查（从决定性事件追到实际结尾）

按任务类型启用；先依据已定事件边界检查，不以最后某个固定百分比代替完整结果链，也不写成全局禁止静止：

- 是否遗漏了既定重要攻击或必要的收束动作；
- 是否过早进入胜利姿态或结局摆拍；
- 是否出现无依据的长时间重复构图、空镜或粒子循环；
- 结尾运动是否真正完成（挥击走完、落地、站稳、收势），还是停在半截；
- 声音是否与画面结果一致（命中、破防、静止、静音）。

发现问题的记录仍按本页 P0／P1 分级；仅为风格选择的静止、留白与反高潮不记失败。

终态有多项要求时分开记，例如“怪物完全消散／山体切开／主角战后状态”，每项给实际时间位置、观察依据与符合／偏离／未知／不适用；冲击帧前后追踪同一次攻击，不能以峰值特效代替结果。部分结果有证据、其余未知时，不汇总成全部通过。开放结尾、未揭示结果不作为缺失项。

本轮关键事件升级的案例对照可使用同一故事的原稿与修订稿，保留角色、能力、强度、时长与终态，预先记录次数及选择方式；逐项检查卡刃破防、唯一终斩、冲击恢复与各终态，并检查原有效的身份、速度和水墨视觉有无退化。入口、绑定或参数未知就记未知，不宣称严格同条件；多项修改仅能评价规则包，单条归因另做单变量测试。执行与观看授权未具备时只保留测试卡，不自动生成。

### 可量化字段

| 字段 | 算法 | 用途 |
| --- | --- | --- |
| 关键接触可见率 | 观察到的预定必要接触数 ÷ 预定必要接触数 | 只数需直接可见的接触；无预定接触时不适用 |
| 破防状态完成率 | 已观察到的预定关键状态变化数 ÷ 预定变化数 | 用于已设破防链；分母为零记不适用 |
| 主动对抗覆盖 | 实际观察阶段逐一记录双方威胁与回应 | 需人工或视觉观察，不以画面运动代替 |
| 无依据停滞时长 | 对明确要求持续动态的区间按原速观察并计时 | 有意停顿、遮挡或证据不足应区分 |
| 材质吻合与状态持续 | 逐项对照指定材质／运动与武器、伤势、场景跨边界状态 | 记录可见依据和不确定处，非关键词自动评分 |
| 终幕可读性 | 观察既定攻击、接触、直接结果与余波是否按作品要求成立 | 原著未揭示或有意留白不补结局 |
| 方向正确率 | 方向正确的攻击镜头 ÷ 总攻击镜头 | 检查左右／目标是否颠倒 |
| 身份稳定率 | 无身份漂移镜头 ÷ 总镜头 | 检查角色串换与漂移 |
| 参考插帧 | 有／无（每条成片） | 参考图是否被当帧 |
| 衔接完整率 | 无跳步的攻防链 ÷ 总攻防链 | 检查回收与下一拍 |
| 命中反馈完整度 | 0～4：接触／材料形变／身体传力／攻方反作用与战局残留 | 检查“打中了”是否只有粒子 |
| 轴线连续 | 逐切镜按既定阅读目标记录通过／不通过／不适用／未知 | 检查越轴与重锚，实验或有意迷向不强套 |
| 背景连续 | 每个切镜是否有共同地标 | 检查换地图 |

计数项目先固定预定事件与观察标准；看不清或不可适用分别记未知／不适用，不作未发生或通过。仅有视频抽帧不能证明完整动态、单独音轨不能证明音画同步；帧差或光流不能单独证明有效对抗。样本很小时只报绝对次数与比例，不写成“显著提升”。3 次生成不足以证明统计显著性；结论写“同条件小样本中未再出现 P0”，不写“成功率 100%”。

## 5. 判定规则

先定判定线，再看片，避免看完再改标准：

- **通过：** 所有生成均无 P0；P1 相对对照版未明显增加，且没有新增 P1 类型；方向正确率与身份稳定率不低于对照版。
- **不通过：** 任一次出现 P0；或 P1 明显增加；或方向／身份指标变差；或差异只来自新增内容而非被测规则。
- **不确定：** 样本不足、模型波动过大、参考素材本身冲突、无法固定关键设置。标“不确定”，不强行宣布升级有效。
- **回归：** 对照版没有的 P0 在新版出现，或 P1 明显增加；先回滚该规则，再查原因。

“更好看”不是通过标准；画面质感与规则遵守分开评价。一个漂亮但攻击方向相反的片段仍是失败样本。

## 6. 失败归因：先分类，再改一条

| 失败类型 | 先查什么 | 不要做什么 |
| --- | --- | --- |
| 方向／左右错误 | 机位与屏幕侧是否一致；越轴后是否重锚；正文是否残留世界方位 | 不要只加“左边、右边”重复强调 |
| 人物漂移／串换 | 参考图职责、角色称谓、同框人数、素材绑定 | 不要靠堆形容词压身份 |
| 参考图插帧 | 参考声明模式、是否误写“静态帧”、素材是否被当成首帧 | 不要把所有参考图声明删掉 |
| 衔接断裂 | 上一击回收、持物手、落脚点、切前相位与切后承接 | 不要用快切掩盖未完成的动作 |
| 命中无反馈 | 接触点、材料、身体传力、攻方反作用、战局残留 | 不要只加粒子和“爆开” |
| 越轴迷向 | 机位运动是否可见、人物换位是否有路径、新镜是否首拍重锚 | 不要用黑场／全屏模糊换侧 |
| 输出未遵循文字 | 查实际提交内容、输入模式、素材、设置与可观察现象 | 不以一次结果断言具体模型原因；证据不足记不确定 |

排查与归因时一次只改一个变量，改完做回归；版本级 A/B 可以测一个规则包，但结论只写“该规则包在这一测试集上的表现”，不把改善归给包内某一条。不要把“加一句禁令”当成修复。若失败来自素材冲突或模型能力，明确说明，不无限重试。

结论句只写实际看到的：

- 可以写：“同条件 3 次生成中，新版未再出现攻击方向 P0；样本小，不能外推。”
- 不要写：“新版彻底解决方向错误，成功率 100%。”
- 没生成时写：“仅完成文字验收，未生成视频，成片效果待核对。”

## 8. 与反馈修订的分工

- 用户回传某条失败视频、截图或抽帧：先用[反馈修订](feedback-repair.md)定位最小失败接点，做局部修订；
- 要判断一个规则／版本是否整体更好：用本页的同条件 A/B，不拿单条成功案例当版本结论；
- 验收发现规则本身有缺口：回到[空间坐标与动态越轴](spatial-coordinate-system.md)或相应专题改规则，再重新跑同一测试集，不用新规则去解释旧失败。
