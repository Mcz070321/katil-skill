# Seedance 2.5 自然语言执行适配

<a id="katil-seedance"></a>

只在[通用适配](model-adaptation.md)的作用域命中时读取；所有通用创作规则仍来自原专题。本页的SD25是维护编号，不能抄进生成正文。参数事实以[能力档案](model-capabilities/seedance-2.5.json)为唯一数值来源，来源原文见档案URL；写法建议不是官方性能保证。

## 十项执行约束

| 规则 | 执行方式 |
| --- | --- |
| SD25-01 保真 | 对照母稿或首轮骨架，保护身份、武器、能力、事件、时长、强度、台词、摄影、声音、语言与结局；只调整未锁定的表达与编排。 |
| SD25-02 渠道 | 平台未知选公开模型基线；指定Runway Tools才读对应模式，其他入口未核验字段保持unknown。已知模型边界持续有效，渠道未知字段不将它覆盖成无限；产品级能力不是所有渠道均开放的证据。 |
| SD25-03 因果节拍 | 主体、动作、目标、可见变化与下一状态相连；同击的光色、火花、形变、声音并入同一事件。默认以无时间码事件编号推进，按 TIME 规则保留锁定微时间线或必要局部时点。可按事件聚合未锁定碎拍；2～6秒仅是可选例子，既非默认镜长也非上下限，不断言碎拍必然丢失。 |
| SD25-04 摄影容量 | 先定观察目标，再组织相容机位路径、朝向、焦点和速度；需要时在相应段首交代镜头路径与屏幕参照。不设镜头数、回合数或字数配额，真一镜不偷切，静止机位同样可用。 |
| SD25-05 素材职责 | 每份实际多模态素材明确提取什么及排除什么；只用真实键，不虚构@。多视板仍是同一角色／武器，版式和展示姿态不入画。职责可在正文开头紧凑合写，不为每张图堆重复禁令。 |
| SD25-06 模式与锁帧 | 先核入口机制再写参考声明。锁帧图删除自身禁入帧句；额外语义图继续保留自己的职责与禁入帧限制。混用是否支持按当前渠道核验，不能让文字禁令覆盖强制首帧机制。 |
| SD25-07 动作／效果 | 仅动作任务检查来袭、具体防守、接触、生效、受力与回收；冲击帧恢复到同一击后续相位。保持指定速度和强度，不靠默认减速或削弱效果换稳定；文戏与恐怖留白不被动作模板接管。 |
| SD25-08 状态 | 切镜与遮挡不刷新手别、数量、伤势、战损、相对位置或运动趋势；先有换手／收放过程再更新。复杂空间用已确认地标与S1／S3表达，S2任务仍保留其世界尺寸用途。 |
| SD25-09 续段／编辑 | 区分文字续写、以前片为参考重新生成、平台Extend及组装。Edit指定时间区间、对象与保留范围；不保证区间外像素绝对不变。 |
| SD25-10 声音／交付 | 按对白、环境、动作、音乐四层和声音目的组织，不新增未授权台词／音乐／字幕。禁音乐不等于静音；只有明确全静音才关闭全部音频。复制块内只放必要画面与声音指令，证据和未决项在块外。 |

例如，用户实际绑定了角色图、场景图和运镜视频时，可以写：“@图片1用于人物外貌、服饰和佩刀；@图片2用于古庙布局与光色；@视频1仅提供环绕路径与格挡节奏，人物和背景按本片重建。”音频再明确是提取音色、内容或节奏；不因参考音乐存在就授权新增BGM。只有用户真的提供上述键时才使用此句中的键。

SD25-03、07、08的联合复核沿用[镜头执行契约](shot-execution-contract.md)：有明确终态时倒推必要条件，冲击帧恢复后逐项承接所需结果，再核来源、变化与持续状态。此处只是通用规则的执行提醒，不新增模型专属镜长、事件配额或稳定性保证；指定小数时间码照原要求保留。

## 模式与输入缺口

四种名称仅在已核验Runway Tools档案中对应实际入口；其他渠道只表示创作意图，不虚构同名按钮或API。

| 意图 | 核对重点 |
| --- | --- |
| Reference | 各素材职责、数量与单份／合计限制分开；无素材不写参考声明或“如有参考图”。 |
| Keyframe | 锁定首尾图和动作衔接。Runway资料明确可同时添加参考素材；未知渠道不能继承该组合支持。图像不可见时不认证起尾构图兼容。 |
| Edit | 真实原片、区间、替换对象与保留项。Runway Edit时长和画幅随原片，无自由时长／画幅控件；不能用提示词保证改变这些设置或区间外完全不动。 |
| Extend | 原片、新增长度、方向及预期整体分别核对。Runway返回新增片段，原片不变；最终文件另行组装，不能称已经合并。Extend画幅随原片。 |

只有素材名称时可写不依赖未知细节的稿；真实原片缺失时只能写编辑／延长意图或文字承接，不称已执行。兼容模式不存在或未知时不虚构可切换入口；同一图既锁首帧又绝不入帧的要求互斥，须指出具体冲突。

## 时长、时间码与实际设置

区分故事总长、单次输出、Extend新增长度和组装总长。超单次上限时保留母稿，给符合用户约束的续段／延长／组装选择，不自动拆成固定长度。真一镜及接缝是否成立需看真实视频；功能支持延长不证明长镜已经成功。

时间表达沿用[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)，普通单段与多段执行稿默认按无时间码事件序。明确要求执行时间码或已有确认技术重叠需换算时，分别注明全局故事码、含技术重叠的源文件局部码，以及剪除重叠后从0开始的新内容局部码，先换算再写对应交付物。换算表和剪辑说明放块外，视频块内保留实际需要的源文件局部范围及匹配动作。重复前片仅属于明确的技术重叠，最终总长扣除实际剪除，不把重播当新事件。锁定总长时不额外添加淡化／过渡；仅有题设长度时报告计划计算，不声称已经剪辑。

时间戳表达用户意图，不认证逐帧命中；Runway资料说明其用于节奏引导。精确时间要求仍保留，块外说明执行未验证，帧级后期处理另列。文案意图与实际控件分开：写“4K质感”不等于原生4K；本地字符长度只是预检，计数机制未说明时不保证等同平台。只有真实独立负向字段存在时才按需单列，不能虚构负向框。

平台资料与用户报告的当前设置冲突时，保留两方来源并重新核验；不挑更宽松上限直接判就绪。发布前、渠道／模式变化或遇到报错时核验能力资料，不在每轮普通创作重复联网。
