# 复杂特效的执行稿编译与保真检查

仅在多角色、多阶段效果、复杂连续性或执行稿出现信息过载时读取。目标是在不改变创作意图和用户锁定要求的前提下，让最终视频提示词优先承载必要的事件、因果和观看目标。无特效、简短表演或低复杂度任务不强制使用本页，不给每个镜头填写表格。

本页是 FX Director、镜头执行契约与交付契约下的操作指南，不取代能力机制、时间、摄影、声音、素材、模型适配或原著权威。用户明确要求最高；本页不新增事件、能力、镜头秒数、音乐或平台能力。

## 一、先形成内部设计，再交付可复制文本

1. **内部设计：** 按任务复杂度梳理用户硬约束、角色与资产、起始／持续状态、必要事件先后、源头与受影响对象、可同事件发生的视听反馈、已要求的结果及余波。区分用户已锁定、导演补充、尚待核实三类信息。无须把十五类、六层、八轨或完整生命周期逐项填满。
2. **外部执行稿：** 以事件或用户指定形式写画面，将同一次动作中相容的光、受力、粒子、环境反馈和允许的声音合并表达。让每个关键变化有可辨的来源、对象和结果，必要时交代方向、位置或环境锚点。长镜、固定机位、主观视点和多镜各按原要求实现。
3. **逐项对照：** 针对本次作品，从需求与内部设计回查执行稿；明确的能力与边界、必经动作、特效强度／覆盖范围、指定数量、观察依据、镜头、时长、语音、结束状态和禁止项均应保留。使用题材本身可观察的依据，用户有意保留未知时不得擅自揭示。
4. **返修顺序：** 先删重复描述和重复声明；再合并同一事件中可并发的反馈；再调整未锁定的摄影、表达顺序或自行补充的次要事件；最后重查状态与关键事件。如果锁定要求之间仍冲突，只说明具体取舍，不擅自删减用户指定内容、降强度、改时长／结局或拆段。

内部设计可以是思考记录或草稿，不要求把一整份设计方案暴露给用户；用户要求同时看母稿时分别交付。未指定字数时不设统一字符上限、镜头配额或压缩率，也不声称越短越好。平台确有字段限制时，先核实渠道与限制；不能无损适配时保留母稿并说明冲突。

## 二、必需保真点与事件依赖

按需检查下列信息，用户未指定且与任务无关的条目不强加：

| 范围 | 检查重点 |
| --- | --- |
| 作品契约 | 总长、段数、语言、媒介、风格、画幅、声音和交付范围，均以用户已确定的为准。 |
| 身份与动作 | 角色数量和位置、武器／手别、能力界限、攻击与应对、动作先后及关键接触或其他关键变化。 |
| 特效因果 | 需要时保留触发源、主要形态／运动、与目标的交互、直接反馈和持续或消散状态；瞬态效果不强制七阶段。 |
| 视觉意图 | 用户指定的高速、全程高强度、满屏、色彩、冲击帧、破坏规模及允许遮挡方式不得擅自降级。 |
| 摄影与素材 | 已绑定素材职责、首尾帧权限、机位约束、空间锚点、观察目标与连续性；不可伪造看图或平台绑定。 |
| 结尾与承接 | 既定结果、余波、伤势／损伤／场地变化、跨镜或跨段尾态；结果成立后不擅自开新回合，用户要求反转或未结束多线时按已有规则处理。 |

先区分**必须先后发生**与**可以同一事件并发**。例如先接触再破裂通常属于先后因果，而伴随同次接触的火星、材质声和环境震动可以并发；不要为了压缩把“已破裂”写到接触之前。用户明确指定反常时间、超现实因果或声画错位时，按其规则表达。

## 三、过载返修示例

下面只演示相同事实如何合并，不是固定句式：

**内部设计：** 角色甲的重斧由右向左砸落；斧刃击中石柱根部；柱根沿冲击方向开裂；同一接触带出碎石与低频撞击声；乙向后撤；烟尘下沉后柱根裂缝保留。用户指定无音乐。

**执行表达：** 甲的重斧由右向左砸中石柱根部，柱根沿冲击方向开裂，碎石与低频撞击声同时爆开；乙后撤，烟尘下沉后裂缝仍留在柱根。无音乐。

两者保留同一接触、方向、反馈、乙的状态、余波及声音限制；没有要求每条反馈拆成单镜。若用户还要求全屏冲击帧或镜头保持固定，也必须写入，不得为了变短将其省略。

**反例：** “斧光爆开，柱子恢复原状，乙被斩杀。”改变了结果、持续状态和未经授权的伤害，即使更短也不合格。

## 四、可复现的文字检查与人工复核

`tests/fx_compilation_cases.json` 给出手工标注的完整设计／执行稿示例，`scripts/fx_compilation_check.py` 只核对标注的原文片段、执行稿片段和明确先后顺序；长度只作参考，不是成功阈值。片段有误、同义改写或重复文本可能导致误报；漏标的用户约束、反义、遮挡、摄影可读性、真实音画效果或语义错误也可能漏报。

机器检查全部通过时仍输出 **ANNOTATED_SPANS_PRESENT_REVIEW_REQUIRED**，只说明所标注的字面证据和顺序存在，必须由实际阅读者对照原始需求与完整稿复核主体、因果、否定、能力、强度、镜头、声音和终态。检查失败时修正文稿或更正有依据的标注后重查。该工具不连接模型，不证明生成效果，也不是平台字符统计器或成片评分器。
