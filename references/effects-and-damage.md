# 特效与受创：视觉发明、尺度演化与作用反馈

> 别名：特效导演。

设计可画出、可推进、真正作用战斗的效果。合理不等于微弱，绚丽不等于多一层泛光。先遵从用户幅度、媒介与世界，再定本场的主形体及变化。

## 1. 能力机制不等于视觉表现上限

机制决定来源、介质／属性、触发、传播／伤害方式、范围与反制，不能擅改。**同机制的表现仍有很大自由**：拓扑、曲率、分层、体积、压密／释放、光色、折射、粒子尺度及时间演化可大胆设计，不把每种表现当新能力。

已授权蓝色热龙焰，可设计互卷长焰舌、滚动体积前沿、撞地翻卷的热浪和蒸散雪雾，仍从龙口输送、前沿到达后受热；不能因此冻结、追踪拐弯、召出独立攻击的实体龙或隔空烧死远军。授权一次落剑震地可有大尺度掀层与延迟坍塌，不自动让此后每挥都有远程剑气。

参考锁身份、设计与媒介，不把单张图恰好弱小的光效当强度上限。要史诗级规模／绚丽时，不能惯性把各层都写成“薄、少量、细小、克制”；真实刀战也不借本页加魔法。可读性靠主次、方向、剪影与时序，不靠全部收小。

## 2. 发明一个清楚的视觉事件

内部为主效果构想少量不同方向，按设定与战术作用择优，不把选择问卷交给用户。依本场选有效变量，不机械每击全用：

候选要在形体组织或演化上真正不同，不是同一光团换颜色。可从本场介质的流动／受压、兵器轨迹、地形结构和人物气质找视觉母形，再让已授权机制把它推到所需幅度。**面对空间、重力、引力、声波、气压等天然无色透明的能力，需要辨识时可选择清楚的折射、可见几何形体、高反差结构或被卷入的环境介质（如按设定可见的引力核心或凝结激波）；若用户指定透明、克制或不可见，保持该设定，借受影响物体、声音或身体反应表达。**例如同为热焰，可沿切入路线拉成压缩扇面，也可撞障后翻成空腔火卷；选哪一种取决于这次接触和战术。沿用上一稿的岩冠、晶体或光圈并非默认答案，不把示例变成全场通用特效，也不要求每招同时使用所有颜色与结构。

| 变量 | 改变画面的选择 |
| --- | --- |
| 主形体与几何 | 扇面、空腔、厚岩层拱起、互卷焰舌、片层、分叉／汇束、断面与卷动前沿，不能只有光团爆开 |
| 内部结构与材质 | 明暗体积、透明外膜、粗大碎块与细粒、内流与外壳，来自本介质，不默认一切晶体化 |
| 运动与变形 | 拉伸、压密、折卷、撕开、回涡、贯入、解体，给过程和方向，不只颜色 |
| 相对尺度 | 人、龙、盾阵、塔、云作比较，留未受影响区域；“最大、万千”不是证据 |
| 光色与光照 | 主色管形体，辅色管边缘／反射，发光、暗核、透射、棱彩分工，照到人地，不全层同亮白雾 |
| 时间演化 | 哪层先压、哪层后展、前沿何时到新对象、残留怎样继续；多阶段不强制多次施法 |
| 战术结果 | 压护位、夺支点、封路、改敌群密度、逼转向、开追击线，下一动作真的利用或应对 |

同是地裂，薄光线加碎石与“地表沿刃线掀成两列厚岩浪，暗板腹和金白断面交替，浪尖在阵前逐段折断”是不同主形体。后者是否选用由授权、场地与容量决定，不是新通用模板。

## 2.1 媒介辨识与空间交互

用户明确指定材质时，检查它的形体、变化、空间关系及与已有对象的作用，不能只替换颜色或堆通用光粒。水墨可按本作选择笔锋、留白、洇染、浓淡和纸质交互；流体可有连贯表面、惯性、分流与再聚；机械效果可体现构件与受力；光可表现散射或折射。上述均是候选，不强迫所有介质符合现实物理，抽象与实验影像按用户约定的美学成立。允许用户要求的混合媒介，不把水墨、粒子和 CG 判作天然互斥。需要细化时读[视觉材质与媒介语法](visual-material-grammar.md)。

## 2.2 多种强效果同时存在时

分别组织各层职责，避免把指定材质统一翻译成彩色烟雾、光带或闪白：

| 层 | 要写清的变化 |
| --- | --- |
| 随动作的材质 | 来源与主形体、如何跟随兵器／身体变形、遇阻后如何压密、折断或分流；不只是颜色拖尾 |
| 接触峰值的冲击帧 | 哪次接触触发、全画幅或局部的图形构成、恢复后接同一次动作的哪个相位 |
| 场景异变与宏观后果 | 从哪个既有物体开始、怎样传播、哪些地标与通路继续有效、如何改变双方行动 |

三层可并发，但要有观看主次：读破防时，以攻击端、目标轮廓、色值分区和运动方向组织强效果；展示空间异变时，让追击穿过变化区域并保留既定空间参照。多次异变可以逐层发展，不强制压成一次或固定拓扑；用户要求空间折叠时，给出其演化和角色去向。

用户要求每击带特效、多次或全画幅冲击帧时，保留这些要求，并按接触作用区分构图与节奏；不默认只留终斩、不统一弱化普通招式。持续剑气与冲击帧分别设计，前者不自动证明后者已发生。精确帧数或持续时间按[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)在明确要求或任务必需的局部给出演出目标，实际逐帧执行另行核验。恢复画面后承接同一动作及其伤势、兵器和方向，不重打。

### 冲击帧之后的结果承接

重要冲击帧按需联查**触发接触或状态变化 → 恢复到同次动作的相位 → 用户要求的直接结果与尾态 → 遮挡是否抹掉必要依据**。全画幅彩墨可占据峰值，恢复画面仍须继承兵器、方向、伤势与环境；不重演命中，也不把恢复后的一次新攻击冒充原攻击的后果。

当用户同时要求怪物完全消散、山体切开及主角战后状态，爆墨本身不证明这三项完成；按镜头执行契约为各项安排可辨依据。并发后果可以同框，不强制降低效果强度、增加慢动作或固定留白；用户指定抽象画面收尾、有意遮挡或开放结尾时保留其意图。

## 3. 阻力、展开与再作用

连接**来源／触发→受压／对抗→形体展开与路径→到达／阻力变化→材料和身体结果→残留／下一威胁**。即发效果可在一次接触内迅速完成，不强制站定蓄力、喊招或每招七层。

先主结构，再中尺度运动与微观装饰。粒子给速度、材质和方向，不能替代大形体与毁坏本身。近处已破、下一层刚抬、远处完整队列仍逼近，尺度与传播才成立。旧破坏的承重、坠落和新路线继续影响后半，不只结尾拉远称顶点。

升级可在覆盖、几何复杂度、形态相变、阻力及波及层级发生，不必每次更亮更大。同色主招也能丰富；不为花样新增未许可属性、召唤和独立命中。

## 4. 命中有对手、有体量

目标抵抗要看见：盾与握把传力、抓地、反推、躲避或甲壳承受，再给成败。重刃可先卷盾缘、屈握盾腕、把肘压向胸，突破后肩胸折转、后脚离撑；攻方也有腕肘受载、刃端减速和支腿接反推。不是每人同姿后仰或瞬间消失。

刃伤、冲击推翻、灼烧、碎片撞击与被同伴挤倒分别写。触及部位、方向、材料、体量决定局部和功能结果；碎盾撞退远排不自动等于远排也被斩死。碾压不强加主角负伤或势均力敌，结果仍须有到达依据。

| 构成 | 反馈方向 |
| --- | --- |
| 金属／机械 | 压痕、弯折、铆接失效、切口、分离、泄漏；实际金属接触才生火花 |
| 石／木／玻璃 | 裂纹、层状折断、纤维拉裂、碎片重量与剩余承重，不都粉化 |
| 水／凝聚体 | 凹陷、卷吸、分流、空腔、失凝或依既定规则再聚；水鲸不自动有血肉 |
| 有机身体 | 按强度写切割／钝击／穿刺／撕裂、失撑和功能结果，不用统一火花代替 |

要求有机断肢／断尾且有血肉时，写作用方式、部位、创口、血液／组织来源和运动、断离去向、剩余肢数与功能丧失，中英转场同伤势。无血、轻伤、非致命按要求，不以肢解补力度。受创后不能用失肢承重或掉刀自动回手。

## 5. 宏观回到交锋

龙在一边喷火、主角在另一边砍，只是并行。火墙封死画面左侧通路后，余敌被迫沿画面右侧完整石脊挤向缺口，主角在回收中改步迎击右侧涌来的新压力，才在同一画面坐标系内形成协同。坠梁要有旧损伤与下落方向，角色让开旧轨迹后仍处理追来兵器；“处理侧击”不能清空第二威胁。

宏观镜头读前沿、主角位置与通路，近镜读接触与身体，不要求万人远景看手指。浓烟、辉光、亮暗突变或短遮挡可有张力，前后以连续方向和定位接回；不能省决定命中的那次接触。

## 6. 效果直接写进正文

默认不制作或附上特效资产图／生图词，不要求用户先准备特效图片。主形体、配色、相对尺度、展开、接触与战术后果直接写入发生的镜头，不把它们藏在另外一份素材里，也不因取消图片而弱化想象力。

用户实际提供特效图时才说明参考范围，并保持图与正文的机制、形态和演化一致；没有图片不写“特效参考图”或待生成占位。用户本轮另要特效图时，可设计有透视、尺度、阻力与环境受光的场面概念，详细交付按[资产专题](asset-prompts.md)，这不是默认步骤。

## 7. 反查

去掉“绚丽／宏伟／震撼”，还能画主形体、空间层与变化吗？去掉“倒下死亡”，还能读被打哪里、怎样失衡、丧失什么功能吗？每次远处变化由哪个到达的前沿触发，又为何改变下一行动？答不了先补设计对抗，不继续贴口号。

需要学习来源时见[制作依据与迁移边界](vfx-study-sources.md)，不默认继续读其他手册。
