# 通用验收：先看任务是否成立，再看画面是否成立

时间表达按[通用创作核心的 TIME 规则](general-creative-core.md#katil-time)检查默认事件序、给定总长与局部精确范围；同时检查删去时码后的事件轻重和终态容量。

所有类型的文字稿与成片验收读本页。动作专项的方向、接触、越轴与命中反馈另按[动作视频验收](video-acceptance-testing.md)；本页负责**契约完整性、模块决策权、意图、叙事、人物、空间、风格、时长、声音与可执行性**。不要用动作 P0 代替通用验收，也不要用“画面好看”代替任务成立。

## 1. 先分清两种验收

| 层级 | 能回答 | 不能回答 |
| --- | --- | --- |
| 文字验收 | 任务契约是否清楚；事件、人物、表演、空间、声音与尾态是否写通；提示词是否可复制 | 模型实际能否生成、成片是否连贯、观众是否真的感动 |
| 视频验收 | 在固定模型与设置下，成片是否出现身份漂移、参考图插帧、空间断裂、时长失控、风格崩坏 | 换模型、换素材、换受众后是否同样成立 |

没有实际生成并观看，只报告“文字设计已改”，不报告“成片已改善”“成功率提高”。

## 2. 通用验收维度

| 维度 | 通过标准 | 失败信号 |
| --- | --- | --- |
| 契约完整 | 主导意图、题材、媒介、形式、导演模式、时长、硬约束与成功标准都清楚 | 只写“电影感”；动画／故事板／广告被当成题材；缺媒介或形式 |
| 模块决策权 | 每个决策域只有一个主导；约束模块不越权；建议模块没有被误当主导 | 动作模块接管文戏；恐怖模块改写爱情；两个模块同时抢同一域 |
| 意图匹配 | 交付物就是用户要的类型、媒介、时长、用途与尺度 | 要文戏给打斗；要广告给世界观；要实验给常规叙事 |
| 叙事清楚 | 谁、在哪、要什么、遇到什么、结果如何，能按顺序读出来 | 只有氛围；靠旁白补因果；转折无依据 |
| 人物与表演 | 行为有目的，情绪有过程，台词有说话者与阶段 | 情绪标签；每句都吼；人物为剧情变笨 |
| 空间可读 | 当前模式（S1／S2／S3）下的左右、前后景、地标、视线与运动方向能连起来 | 无因越轴；切镜换地图；人物瞬移；把 S1 禁米数套到 S2 |
| 风格与媒介 | 真人／二维／三维／定格／实验语言一致；画风服务内容 | 把真人物理套给动画；把动画当低幼 |
| 节奏与时长 | 事件装得下；该长则长，该短则短；分段有承接 | 平均分镜；为凑时长加空镜；对白超容量 |
| 声音 | 对白、环境、动作、静默、音乐各司其职；音乐与文字按默认矩阵的声音目的判断 | 未指定却铺满 BGM；音乐主导任务没有音乐结构；声画不同步；听不清台词 |
| 提示词可执行 | 可复制、事实一致、无工程说明混入、参考职责清楚 | 块内混入内部世界图、表单标题、分析 |
| 创意概念 | 有作者空间时概念与人物、任务或可观察表达相关；功能展示可以极简 | 为奇观凭空新增事实或强加象征 |
| 关键变化的观察依据 | 重要变化按需要由画面、声音或有意的后续线索支撑；留白依原意 | 用“发生了”代替必要证据，或强行揭穿悬念 |
| 终幕与节奏 | 结尾符合用户的事件、媒介与速度要求；不无故丢动作或拖延 | 固定英雄摆拍或为证明完整而补结局 |
| 伦理与合规 | 不伪造事实、不消费苦难、不夸大产品功效、尊重人物 | 假纪录片、假数据、歧视性恐怖符号 |

## 3. 分级：P0、P1、P2

### 通用 P0（一票否决）

- 交付物与用户任务根本不符（要文戏给打斗、要广告给无关短片、要单语给双语且用户明确拒绝）。
- 核心人物身份／服装／物种／媒介在镜头间无过程串换，导致故事读错。
- 在禁止参考图直接入帧的任务中，参考图被当作静态帧、拼贴或分镜板直接插入成片；明确锁定首尾帧时按用户要求判定。
- 关键事件缺失、因果断裂，观众无法理解发生了什么。
- 时长／分段与用户硬约束严重冲突，且未说明。
- 产品广告出现虚假功效、伪造对比或违反用户给的合规边界。
- 真实事件／人物被伪造或移花接木。

### 通用 P1（明显缺陷）

- 叙事靠旁白解释，画面没有支撑。
- 表演只有情绪标签，没有可看见的行为过程。
- 空间关系需要反复暂停才能看懂；共同地标丢失。
- 风格在中途无因漂移；二维／三维语言混用没有设计。
- 节奏明显失衡：该停顿的地方赶、该快的地方拖。
- 对白与口型／发声阶段明显不匹配；音乐盖掉关键台词。
- 结尾自动加胜利摆拍、烟尘空场、新敌人或解释性旁白。

### P2（细节瑕疵）

手指、碎片、纹理、光影、衣摆、轻微穿模等不影响任务阅读的问题。单独记录，不与 P0／P1 混算。

动作任务另有动作 P0（方向错误、接触缺失、武器肢体瞬移等），按[动作视频验收](video-acceptance-testing.md)执行；文戏、广告、恐怖、爱情不套用这些动作 P0。

## 4. 题材、媒介、形式与模式专项检查

| 维度 | 必须检查 | 不要用 |
| --- | --- | --- |
| 叙事／文戏（题材） | 场景变化、人物目标、潜台词、表演过程、结尾余波 | 动作 P0；慢镜与配乐代替表演 |
| 动作（题材） | 攻防因果、接触、受力、手别、空间轴线、尾态 | 只用通用“好看”标准 |
| 恐怖（题材） | 恐惧来源、信息延迟、空间、声音、jump scare 是否有积累 | 血腥程度当恐怖质量 |
| 爱情（题材） | 关系变化、同意与边界、潜台词、日常细节 | 狗血误会、跟踪当浪漫 |
| 科幻／奇幻（题材） | 世界规则、能力代价、设定信息是否跟人物需求出现 | 特效规模当世界观深度 |
| 现实主义（导演模式） | 因果、生活细节、光声、伦理 | 灰蓝滤镜当真实 |
| 广告（形式／用途） | 单一诉求、产品证据、产品一致性、合规、结尾 | 剧情抢产品；卖点堆砌 |
| 动画（媒介） | 媒介语法、姿势与时间、角色一致性、镜头与透视 | 真人规则硬套 |
| 故事板／长视频（形式） | 空间方向、连续性、分段承接、节奏、格数／画幅 | 平均分镜；每段重启世界 |
| 混合任务 | 每个维度是否有唯一主导；媒介与形式是否分开；动作是否只在动作题材加载 | 只定一个主类型＋一个副模块；动作抢走文戏 |

## 5. 同条件视频验收

需要判断规则／版本是否真的改善成片时：

1. 固定模型、素材、时长、画幅、分辨率、帧率、种子（若开放）、参考强度、负向词与生成次数。
2. 先定测试集：覆盖任务契约的每个维度；混合类型至少覆盖两个题材、一个媒介与一个形式，不只加一个副类型。
3. 先定判定线，再看片；不看完再改标准。
4. 每版至少 3 次；样本不足标“不确定”，不写“显著提升”。
5. 单变量 A/B 保持其他影响尽可能一致；版本整包比较可允许各版选择不同摄影设计，但必须保留同题要求与事实，记录所有可见差异，结论只归于整包。不得擅改已锁定的镜头数量、事件与结局。

动作专项测试集与 P0 见[动作视频验收](video-acceptance-testing.md)；通用测试集建议：

| 场景 | 检查 |
| --- | --- |
| 安静对话／告别 | 表演、潜台词、空间、声音、结尾 |
| 高强度动作 | 因果、接触、方向、连续性 |
| 恐怖／悬疑 | 信息延迟、空间、声音、jump scare 积累 |
| 产品广告 | 单一诉求、产品证据、产品一致性、合规 |
| 动画／风格化 | 媒介语法、角色一致性、运动规则 |
| 建筑／产品空间展示 | S2 世界坐标是否可读；有没有误套 S1 禁米数 |
| 混合类型 | 每个维度是否有唯一主导；动作是否被误加载；媒介与形式是否分开 |

跨类型路由本身是否读对，另按[跨类型路由回归](routing-regression.md)的 20 条固定用例抽检；不要用一条“混合类型”场景代替全部维度。

## 6. 判定与报告

- **通过：** 无 P0；P1 在可接受范围；与对照版相比没有新增同类问题。
- **不通过：** 任一 P0；或核心任务不成立；或 P1 明显增加。
- **不确定：** 样本不足、模型波动大、素材冲突、关键设置无法固定。
- **回归：** 对照版没有的 P0 在新版出现，或 P1 明显增加；先回滚该规则。

| 维度 | 被测 | 对照 | 备注 |
| --- | --- | --- | --- |
| 意图匹配 |  |  |  |
| 叙事清楚 |  |  |  |
| 人物与表演 |  |  |  |
| 空间可读 |  |  |  |
| 风格与媒介 |  |  |  |
| 节奏与时长 |  |  |  |
| 声音 |  |  |  |
| 可执行性 |  |  |  |

P0：
P1：

结论句只写实际看到的：

- 可以写：“同条件 3 次生成中，新版未再出现身份串换 P0；样本小，不能外推。”
- 不要写：“新版彻底解决所有问题，成功率 100%。”
- 没生成时写：“仅完成文字验收，未生成视频，成片效果待核对。”

## 7. 可选评分（只作横向比较，不作绝对质量证明）

用户需要版本对比时，可按下列权重做主观评分；分数只评价规则设计与文字稿，不代表成片成功率。

| 维度 | 权重 |
| --- | --- |
| 通用任务理解与适配 | 20% |
| 叙事与创意 | 15% |
| 导演运镜与空间组织 | 15% |
| 动作、表演与物理逻辑 | 15% |
| 视觉风格与特效系统 | 15% |
| 提示词执行性与效率 | 10% |
| 连续性与质量验收 | 10% |

动作专项另做专项评测，不挤占通用分。评分时写明“主观、基于文字稿、未做视频 A/B”。

## 8. 常见错误

- 用动作 P0 检查文戏，得出“没有命中反馈所以失败”。
- 把动画、故事板、广告当成题材，漏掉媒介、形式与导演模式。
- 只检查“一个主类型＋一个副模块”，没有检查每个决策域的主导权。
- 用“画面好看”代替“任务成立”。
- 只看单条成功案例，宣布版本升级有效。
- 不固定模型与素材，却比较两个版本。
- 把样本不足写成“趋势明显”。
- 把模型限制写成提示词规则缺陷。
- 只检查画面，不检查声音、时长、合规与伦理。

**检查：先问“用户要的东西成立了吗”，再问“画面好看吗”。顺序反了，验收就会跑偏。**

## 同题文字回归的篇幅复查

比较旧版和新版时，可测量同题、同范围、同语言复制块的实际长度；若新版相对旧版增长超过约10%，逐段检查增加内容是否为用户约束、必要因果、清晰表达或媒介设计所需，删除重复与无依据铺陈。10%只是回归审查目标，不是固定上限、模型容量结论或删减必要内容的理由；没有可比较的基线就不编造比例。文字对照结果不能证明视频表现。
